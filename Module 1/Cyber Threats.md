# 🛡️ UNDERSTAND CYBER THREATS

> ### 🔐 Cybersecurity Foundation Notes
> **Learn how threats, vulnerabilities, risks, exploits, and attack vectors are connected.**

---

## ⚠️ A. THREATS

### 🔎 What is a Threat?

A **threat** is anything that has the potential to cause **harm, damage, disruption, or unauthorized access** to a computer system, network, application, or data.

### 📌 Examples

- 🦠 Malware
- 🎣 Phishing
- 👤 Insider threats
- 💻 Cybercriminals
- 🌐 Denial-of-Service (DoS) attacks

> 💡 **Example:** A hacker attempting to steal user passwords is a **threat**.

---

## 🕳️ B. VULNERABILITIES

### 🔎 What is a Vulnerability?

A **vulnerability** is a **weakness or security flaw** in a system that can potentially be exploited by a threat.

### 📌 Examples

- 🔑 Weak passwords
- 📦 Outdated software
- ⚙️ Misconfigured servers
- 🐛 Unpatched security bugs
- 🚪 Poor access controls

> 💡 **Example:** An outdated application containing a known security flaw is a **vulnerability**.

---

## 🎯 C. RISKS

### 🔎 What is Risk?

**Risk** is the possibility that a threat will exploit a vulnerability and cause **damage, loss, or disruption**.

### 📐 Basic Concept

> **Risk = Threat × Vulnerability × Potential Impact**

### 📌 Examples

- 💾 Data loss
- 💰 Financial loss
- 🔒 Privacy breaches
- 🌐 Service disruption
- 📉 Reputation damage

> 💡 **Example:** If a company has weak passwords and attackers are actively targeting its accounts, the company has a **higher security risk**.

---

## 💥 D. EXPLOITS

### 🔎 What is an Exploit?

An **exploit** is a **technique, method, or piece of code** designed to take advantage of a vulnerability.

### 📌 Examples

- 🐛 Exploiting a software vulnerability
- 🔑 Taking advantage of weak authentication
- 🌐 Exploiting vulnerable web applications

> 💡 **Example:** If a web application contains a security flaw and an attacker uses a technique to take advantage of it, that technique is an **exploit**.

---

## 🛣️ E. ATTACK VECTORS

### 🔎 What is an Attack Vector?

An **attack vector** is the **path, method, or entry point** an attacker uses to reach and compromise a target.

### 📌 Common Attack Vectors

- 🎣 Phishing emails
- 🌐 Malicious websites
- 🔑 Compromised accounts
- 📎 Malicious files
- 🖥️ Vulnerable applications
- 🧠 Social engineering
- 📡 Unsecured networks

> 💡 **Example:** An attacker sends a fake email containing a malicious link. The **phishing email is the attack vector**.

## 🧠 Quick Difference

| 🔐 Concept | 📖 Meaning |
|---|---|
| ⚠️ **Threat** | A potential source of harm |
| 🕳️ **Vulnerability** | A weakness that can be exploited |
| 🎯 **Risk** | The possibility and impact of harm |
| 💥 **Exploit** | A method used to take advantage of a weakness |
| 🛣️ **Attack Vector** | The path used to carry out an attack |
