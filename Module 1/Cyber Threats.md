# 🔐 Understand Cyber Threats

Cyber threats are potential dangers or malicious activities that can harm computer systems, networks, applications, or data. Understanding threats helps organizations identify weaknesses and protect their digital assets.

## a. ⚠️ Threats

A threat is anything that has the potential to cause harm to a system or its information.

### Examples:

- Malware
- Phishing
- Data theft
- Unauthorized access
- Denial-of-Service (DoS) attacks

**Example:** An attacker attempting to steal someone's password is a cyber threat.

## b. 🕳️ Vulnerabilities

A vulnerability is a weakness or security flaw in a system that could be exploited by an attacker.

### Examples:

- Weak passwords
- Outdated software
- Misconfigured servers
- Unpatched security vulnerabilities
- Poor access controls

**Example:** Using an old version of software with a known security flaw creates a vulnerability.

## c. 🎯 Risks

Risk is the possibility of harm or loss resulting from a threat taking advantage of a vulnerability.

A simple way to understand it is:

**Risk = Threat + Vulnerability + Potential Impact**

### Examples:

- A weak password could allow unauthorized access.
- A vulnerable server could lead to data loss.
- Poor security controls could expose sensitive information.

## d. 💥 Exploits

An exploit is a technique, method, or piece of code used to take advantage of a vulnerability.

### Example:

**Vulnerability → Exploit → Unauthorized Access**

If a website contains a known security flaw, an attacker may use an exploit to take advantage of that flaw.

**Important:** Security professionals also use exploits in authorized testing to identify and fix vulnerabilities.

## e. 🚪 Attack Vectors

An attack vector is the path or method an attacker uses to reach and compromise a target.

### Common attack vectors include:

- 📧 Phishing emails
- 🌐 Malicious websites
- 🔑 Stolen credentials
- 📁 Malicious files
- 🖥️ Vulnerable applications
- 📱 Compromised devices
- 🌐 Insecure networks

### Example:

An attacker sends a phishing email → the victim clicks a malicious link → credentials are stolen.

---

## 🧠 Quick Difference

| Term | Meaning |
|------|---------|
| Threat | Something that can cause harm |
| Vulnerability | A weakness that can be exploited |
| Risk | The potential for damage or loss |
| Exploit | A method used to take advantage of a weakness |
| Attack Vector | The path used to carry out an attack |

---

## 🔄 Simple Example

1. **Threat:** Attacker wants to steal data
2. ⬇️ **Vulnerability:** Unpatched application
3. ⬇️ **Exploit:** Attacker takes advantage of the flaw
4. ⬇️ **Attack Vector:** Internet-facing application
5. ⬇️ **Risk:** Data may be accessed or stolen
