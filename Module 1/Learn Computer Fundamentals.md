# 💻 Learn Computer Fundamentals

## 🧩 1. Basic Computer Components

### ⚙️ CPU — Central Processing Unit

The **CPU** is the brain of the computer. It processes instructions and performs calculations.

**Main functions:**

* Executes instructions
* Performs calculations
* Controls other computer components

### 🧠 Memory — RAM

**RAM (Random Access Memory)** temporarily stores data and programs that are currently being used.

* Fast but temporary
* Data is lost when the computer is turned off
* More RAM allows better multitasking

### 💾 Storage

Storage keeps data **permanently**, even when the computer is turned off.

**Examples:**

* HDD — Hard Disk Drive
* SSD — Solid State Drive
* USB flash drive
* Memory card

---

## 🖥️ 2. Hardware and Software

### 🔩 Hardware

**Hardware** refers to the physical parts of a computer that you can touch**(Tangible)**.

**Examples:**

* CPU
* RAM
* Keyboard
* Mouse
* Monitor
* SSD/HDD

### 💿 Software

**Software** is a set of programs and instructions that tells the hardware what to do.

**Examples:**

* Windows
* Linux
* macOS
* Web browsers
* Games
* Antivirus software

> **Simple difference:** Hardware is what you **can touch**, while software is what you **run**.

---

## 🔢 3. Binary Data

Computers store and process information using **binary**, which has only two values:

* `0` → OFF
* `1` → ON

A single binary digit is called a **bit**.

### 📦 Bits and Bytes

* **1 bit** = `0` or `1`
* **8 bits** = **1 byte**
* Larger units include KB, MB, GB, and TB.

For example:

```text
01000001
```

This is a sequence of 8 bits that can represent a character such as **A** using a character encoding system.

Computers use binary patterns to represent **text, numbers, images, audio, videos, and programs**.

---

## 🛡️ Key Takeaway

Understanding **CPU, memory, storage, hardware, software, and binary data** gives you the basic knowledge needed to understand how computers work and provides a foundation for learning **cybersecurity**.
