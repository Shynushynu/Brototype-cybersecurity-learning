## 🔹 1. Importing Modules

Importing modules means using code that is already written in another Python file or a built-in library.

### Example

```python
import math

print(math.sqrt(25))
```

**Output:**
```text
5.0
```

### Common Import Methods

```python
import math
```

Imports the complete module.

```python
from math import sqrt

print(sqrt(25))
```

Imports a specific function from a module.

```python
import math as m

print(m.sqrt(25))
```

Imports a module using an alias.

## 🔹 2. Creating Modules

A Python module is simply a Python file (`.py`) containing reusable code.

### Example

Create a file named `security.py`:

```python
def check_password(password):
    if len(password) >= 8:
        return "Password length is acceptable"
    return "Password is too short"
```

Create another file named `main.py`:

```python
import security

print(security.check_password("hello123"))
```

**Output:**
```text
Password length is acceptable
```

**Key point:** We can use functions from `security.py` in `main.py` by importing the module.

## 🔹 3. Package Management

Package management means installing, updating, and managing external Python packages.

A **package** provides reusable code that can be used in Python programs.

### Example: Installing a Package

```bash
pip install requests
```

### Using the Package

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

**Output:**
```text
200
```

The exact status code depends on the server's response.

### Useful Commands

| Command | Purpose |
|---|---|
| `pip install requests` | Install a package |
| `pip show requests` | Display package information |
| `pip list` | List installed packages |
| `pip uninstall requests` | Uninstall a package |

## 🔹 4. Virtual Environments

A virtual environment creates an isolated Python environment for a project. It helps prevent package-version conflicts between different projects.

### Creating a Virtual Environment

```bash
python -m venv venv
```

### Activating on Windows

```powershell
venv\Scripts\activate
```

### Activating on Linux

```bash
source venv/bin/activate
```

### Installing a Package Inside the Environment

```bash
python -m pip install requests
```

### Deactivating the Environment

```bash
deactivate
```

**Key point:** Virtual environments help each project maintain its own dependencies.

## 🔹 5. Reusable Security Tools

Reusable security tools are Python scripts or modules that can be used repeatedly for cybersecurity tasks.

Instead of writing the same code again and again, we can create functions and import them into different programs.

### Example: IP Address Validator

Create `security_tools.py`:

```python
import ipaddress

def validate_ip(ip):
    try:
        ipaddress.ip_address(ip)
        return "Valid IP address"
    except ValueError:
        return "Invalid IP address"
```

Create `main.py`:

```python
import security_tools

print(security_tools.validate_ip("192.168.1.1"))
print(security_tools.validate_ip("999.999.1.1"))
```

**Output:**
```text
Valid IP address
Invalid IP address
```

### Applications in Cybersecurity

- 🔍 Validating IP addresses
- 📄 Analyzing log files
- 🔐 Checking password policies
- 🌐 Processing network information
- 🛡️ Automating authorized security checks
