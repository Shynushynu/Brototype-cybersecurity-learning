## 📊 Collection Types

| Collection     | Ordered | Changeable | Duplicates | Example             |

| **List**       |    ✅    |      ✅     |      ✅     | `[10, 20, 30]`      |

# 1. 📋 Lists

A **list** stores multiple values and can be changed after creation.

```python
fruits = ["apple", "banana", "orange"]
```

### Accessing List Values

Python uses **index numbers**, starting from `0`.

```python
print(fruits[0])
```

Output:

```text
apple
```

```text
Index:     0          1          2
          apple      banana     orange
```

### Changing a List Value

```python
fruits[1] = "mango"

print(fruits)
```

Output:

```text
['apple', 'mango', 'orange']
```

### Useful List Methods

```python
fruits.append("grape")      # Add an item
fruits.remove("apple")      # Remove an item
fruits.pop()                # Remove the last item
fruits.insert(1, "kiwi")    # Insert an item
```

---

# 2. 🔒 Tuples

A **tuple** is similar to a list, but its values **cannot be changed** after creation.

```python
coordinates = (10, 20)
```

### Accessing Tuple Values

```python
print(coordinates[0])
```

Output:

```text
10
```

### Tuples Are Immutable

The following will cause an error:

```python
coordinates[0] = 50
```

This is because tuples are **immutable**, meaning their values cannot be changed after creation.

### When to Use a Tuple?

Use a tuple when the data **should not change**.

```python
server = ("192.168.1.10", 80)
```

---

# 3. 🎯 Sets

A **set** stores **unique values**.

```python
numbers = {10, 20, 30, 10, 20}

print(numbers)
```

The duplicate values are automatically removed.

Output:

```text
{10, 20, 30}
```

### Removing Duplicates Using a Set

Suppose we have:

```python
names = ["Alex", "John", "Alex", "Mike", "John"]
```

We can remove duplicates using `set()`:

```python
unique_names = set(names)

print(unique_names)
```

Result:

```text
{'Alex', 'John', 'Mike'}
```

### ⚠️ Important

Sets do not support index-based access.

This will cause an error:

```python
numbers[0]
```

# 4. 📖 Dictionaries

A **dictionary** stores data as **key-value pairs**.

```python
student = {
    "name": "Shynu",
    "age": 18,
    "course": "Cybersecurity"
}
```

Think of it like this:

```text
Key       → Value
-------------------------
name      → Shynu
age       → 18
course    → Cybersecurity
```

### Accessing a Dictionary Value

```python
print(student["name"])
```

Output:

```text
Shynu
```

### Changing a Dictionary Value

```python
student["age"] = 19
```

### Adding a New Value

```python
student["place"] = "Alappuzha"
```

### Removing a Value

```python
student.pop("age")
```

# 5. 🛠️ Collection Manipulation

**Collection manipulation** means performing operations on collections, such as:

- ➕ Adding values
- ❌ Removing values
- ✏️ Changing values
- 🔍 Searching
- 🔃 Sorting
- 🔁 Looping
- 🔗 Combining collections

### Example with a List

```python
numbers = [5, 2, 8, 1, 3]

numbers.append(10)

numbers.remove(2)

numbers.sort()

print(numbers)
```

Output:

```text
[1, 3, 5, 8, 10]
```

---

# 🔄 Looping Through Collections

## Loop Through a List

```python
fruits = ["apple", "banana", "orange"]

for fruit in fruits:
    print(fruit)
```

---

## Loop Through a Tuple

```python
numbers = (10, 20, 30)

for number in numbers:
    print(number)
```

---

## Loop Through a Set

```python
numbers = {10, 20, 30}

for number in numbers:
    print(number)
```

> The order of output from a set is not guaranteed.

---

## Loop Through a Dictionary

```python
student = {
    "name": "Shynu",
    "age": 18
}

for key, value in student.items():
    print(key, value)
```

Output:

```text
name Shynu
age 18
```

# 🔐 Real-World Cybersecurity Example

Python collections can be useful when working with cybersecurity data.

### 📋 List

Store commonly used ports:

```python
ports = [22, 80, 443, 8080]
```

### 🔒 Tuple

Store server information:

```python
server = ("192.168.1.10", 443)
```

### 🎯 Set

Store unique IP addresses:

```python
unique_ips = {
    "10.0.0.1",
    "10.0.0.2",
    "10.0.0.1"
}
```

The duplicate IP is automatically removed.

### 📖 Dictionary

Store user information:

```python
user = {
    "username": "admin",
    "role": "analyst",
    "active": True
}
```
