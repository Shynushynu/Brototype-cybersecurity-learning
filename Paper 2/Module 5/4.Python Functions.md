# 🐍 4. Understand Functions

A **function** is a reusable block of code that performs a specific task.

Instead of writing the same code again and again, we can put it inside a function and use it whenever we need it.

## 1. Function Creation

We create a function using the `def` keyword.

### Syntax

```python
def function_name():
    # code
```

### Example

```python
def greet():
    print("Hello!")
```

Here:

- `def` → tells Python we are creating a function
- `greet` → function name
- `()` → holds parameters if needed
- `:` → starts the function body

Creating a function doesn't run it.

We need to **call** the function:

```python
greet()
```

Output:

```text
Hello!
```

### 💡 Simple Idea

```text
Create function → Call function → Code runs
```

## 2. Parameters

A **parameter** is a value that we give to a function so it can work with different data.

```python
def greet(name):
    print("Hello", name)

greet("Shynu")
greet("Rahul")
```

Output:

```text
Hello Shynu
Hello Rahul
```

Here, `name` is the **parameter**.

When we call:

```python
greet("Shynu")
```

`"Shynu"` is the **argument**.

### 💡 Easy Way to Remember

```text
Parameter = Placeholder
Argument  = Actual Value
```

### Example

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

Here:

- `a` and `b` → parameters
- `10` and `20` → arguments

## 3. Return Values

A function can **return a result** using `return`.

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

Output:

```text
30
```

### 🔄 What Happens?

```text
add(10, 20)
      ↓
  10 + 20
      ↓
     30
      ↓
  return 30
      ↓
 result = 30
```

### `print()` vs `return`

**`print()`** → displays something on the screen.

**`return`** → sends a value back to where the function was called.

#### Using `print()`

```python
def add(a, b):
    print(a + b)
```

This displays the answer.

#### Using `return`

```python
def add(a, b):
    return a + b
```

This gives the answer back so we can store or use it.

```python
x = add(5, 3)
print(x)
```

Output:

```text
8
```

## 4. Scope

**Scope** means **where a variable can be accessed**.

There are two important types:

### 🔹 Local Variable

A variable created inside a function is usually **local** to that function.

```python
def test():
    x = 10
    print(x)

test()
```

This works because `x` is being used inside the function.

But:

```python
def test():
    x = 10

test()

print(x)
```

This causes an error because `x` exists only inside `test()`.

### 🔹 Global Variable

A variable created outside a function can generally be accessed inside the function.

```python
x = 10

def test():
    print(x)

test()
```

Output:

```text
10
```

### 💡 Simple Idea

```text
Global variable
      ↓
Can be accessed from different places

Local variable
      ↓
Belongs to the function
```

## 5. Reusable Code

One of the biggest advantages of functions is **code reuse**.

### ❌ Without a Function

```python
print("Hello Shynu")
print("Hello Rahul")
print("Hello Anu")
```

### ✅ With a Function

```python
def greet(name):
    print("Hello", name)

greet("Shynu")
greet("Rahul")
greet("Anu")
```

We write the logic **once** and use it multiple times.

---

## 🔐 Real-World Example

Imagine a cybersecurity program that checks whether a password is long enough.

```python
def check_password(password):
    if len(password) >= 8:
        return True
    else:
        return False

print(check_password("hello123"))
```

Output:

```text
True
```

We can reuse the same function:

```python
print(check_password("abc"))
print(check_password("password123"))
print(check_password("hello12345"))
```

The function performs the same task with different passwords.

## ⭐ Basic Function Structure

```python
def function_name(parameter):
    # do something
    return result
```

### Example

```python
def multiply(a, b):
    return a * b

answer = multiply(5, 4)

print(answer)
```

Output:

```text
20
```

### 🔍 Breaking It Down

```text
def       → Create a function
multiply  → Function name
a, b      → Parameters
5, 4      → Arguments
return    → Send result back
answer    → Stores returned result
```
