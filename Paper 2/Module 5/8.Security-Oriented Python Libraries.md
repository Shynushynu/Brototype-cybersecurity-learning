## 1. Requests 🌐

### What is Requests?

The `requests` library allows Python to send HTTP requests to websites and web servers.

### Main Uses

- `GET` — Retrieve data from a website.
- `POST` — Send data to a server.
- Check HTTP status codes.
- Retrieve website responses and headers.

### Example

```python
import requests

response = requests.get("https://example.com")

print(response.status_code)
print(response.text)
```

### Explanation

- `import requests` — Imports the Requests library.
- `requests.get()` — Sends an HTTP GET request.
- `response.status_code` — Displays the HTTP status code.
- `response.text` — Displays the response body as text.

**Output:** The status code is usually `200` when the request succeeds.

### Cybersecurity Uses

- Checking website availability.
- Retrieving HTTP headers for security analysis.
- Interacting with security-related APIs.
- Automating web-based tasks.

**Note:** Install the library using `pip install requests` if it is not already installed.

## 2. JSON 📦

### What is JSON?

JSON (JavaScript Object Notation) is a format used to store and exchange structured data.

Python provides a built-in `json` module.

### Important Functions

| Function | Purpose |
|---|---|
| `json.dumps()` | Converts Python data into a JSON string |
| `json.loads()` | Converts a JSON string into Python data |
| `json.dump()` | Writes Python data to a JSON file |
| `json.load()` | Reads JSON data from a file |

### Example

```python
import json

user = {
    "username": "shynu",
    "role": "student"
}

data = json.dumps(user)

print(data)
```

### Output

```json
{"username": "shynu", "role": "student"}
```

### Explanation

- `import json` — Imports Python's JSON module.
- `user` — Stores information in a Python dictionary.
- `json.dumps(user)` — Converts the dictionary into a JSON string.
- `print(data)` — Displays the JSON string.

### Cybersecurity Uses

- Processing API responses.
- Reading configuration files.
- Storing security event data.
- Exchanging information between security tools.

**Note:** JSON is built into Python, so no separate installation is required.

## 3. OS 🖥️

### What is OS?

The `os` module allows Python to interact with the operating system, including files, folders, and directories.

### Important Functions

| Function | Purpose |
|---|---|
| `os.getcwd()` | Gets the current working directory |
| `os.listdir()` | Lists files and folders |
| `os.mkdir()` | Creates a directory |
| `os.path.exists()` | Checks whether a path exists |

### Example

```python
import os

print(os.getcwd())
print(os.listdir())
```

### Explanation

- `os.getcwd()` — Displays the current working directory.
- `os.listdir()` — Displays the files and folders in that directory.

### Cybersecurity Uses

- Automating file management.
- Organizing security logs.
- Checking whether files and directories exist.
- Creating directories for security projects.

**Note:** The `os` module is built into Python.

## 4. Socket 🔌

### What is Socket?

The `socket` module enables network communication between computers using protocols such as TCP and UDP.

### Main Uses

- Creating network connections.
- Building client-server applications.
- Working with IP addresses and ports.
- Learning network communication.

### Example

```python
import socket

client = socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)

client.settimeout(3)

result = client.connect_ex(("example.com", 80))

if result == 0:
    print("Connection successful")
else:
    print("Connection failed")

client.close()
```

### Explanation

- `socket.AF_INET` — Uses IPv4 addressing.
- `socket.SOCK_STREAM` — Creates a TCP socket.
- `client.settimeout(3)` — Sets a three-second connection timeout.
- `connect_ex()` — Attempts a connection and returns an error code instead of raising an exception for a connection failure.
- `client.close()` — Closes the socket.

**Note:** Port 80 is commonly used for HTTP. A successful connection does not guarantee that the website is fully functioning.

### Cybersecurity Uses

- Learning TCP/IP communication.
- Building basic network diagnostic tools.
- Understanding client-server connections.
- Testing connectivity to authorized systems.

**Safety:** Only test systems and ports you own or have permission to assess.

## 5. Subprocess ⚙️

### What is Subprocess?

The `subprocess` module allows Python to execute external programs and system commands.

### Main Uses

- Running system commands.
- Launching external programs.
- Capturing command output.
- Automating system administration tasks.

### Example

```python
import subprocess

result = subprocess.run(
    ["python", "--version"],
    capture_output=True,
    text=True
)

print(result.stdout)
```

### Example Output

```text
Python 3.x.x
```

The exact version depends on the Python installation.

### Explanation

- `subprocess.run()` — Executes an external command.
- `capture_output=True` — Captures standard output and standard error.
- `text=True` — Returns captured output as strings.
- `result.stdout` — Displays the command's standard output.

### Cybersecurity Uses

- Automating system administration.
- Running authorized security tools.
- Collecting diagnostic information.
- Automating repetitive tasks.

**Security Tip:** Prefer passing commands as a list. Avoid `shell=True` with untrusted input because it can introduce command-injection vulnerabilities.
