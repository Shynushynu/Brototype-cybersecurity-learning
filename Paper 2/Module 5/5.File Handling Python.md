## 📖 1. Reading Files

**Reading files** means opening a file and accessing the information stored inside it.

### Example

Assume `data.txt` contains:

```text
Hello Python!
Welcome to file handling.
```

### Python Code

```python
file = open("data.txt", "r")

content = file.read()

print(content)

file.close()
```

### Output

```text
Hello Python!
Welcome to file handling.
```

### Important Methods

| Method | Purpose |
|---|---|
| `read()` | Reads the entire file |
| `readline()` | Reads one line |
| `readlines()` | Reads all lines into a list |
| `close()` | Closes the file |

### Reading Line by Line

```python
with open("data.txt", "r") as file:
    for line in file:
        print(line.strip())
```

**Remember:** `strip()` removes surrounding whitespace, including the newline at the end of a line.

## ✍️ 2. Writing Files

**Writing files** means saving information into a file.

### Example

```python
with open("data.txt", "w") as file:
    file.write("Hello Python!")
```

This creates `data.txt` if it does not exist. If it already exists, `"w"` replaces its existing content.

### Adding Content Without Replacing Existing Content

Use `"a"` (append mode).

```python
with open("data.txt", "a") as file:
    file.write("\nWelcome to Python!")
```

### Important File Modes

| Mode | Meaning |
|---|---|
| `"r"` | Read an existing file |
| `"w"` | Write; replace existing content |
| `"a"` | Append content to the end |
| `"x"` | Create a new file; fail if it exists |
| `"r+"` | Read and write without automatically truncating the file |

**Important:** Writing to a file can permanently replace existing content. Use `"w"` carefully.

## 📊 3. CSV Processing

**CSV** stands for *Comma-Separated Values*.

It stores information in rows and columns, similar to a spreadsheet.

### Example: `users.csv`

```csv
name,role
Shynu,Student
Alex,Admin
Sam,Analyst
```

### Reading a CSV File

```python
import csv

with open("users.csv", "r", newline="") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

### Output

```text
['name', 'role']
['Shynu', 'Student']
['Alex', 'Admin']
['Sam', 'Analyst']
```

Each row is returned as a list of strings.

### Reading CSV Using Dictionaries

```python
import csv

with open("users.csv", "r", newline="") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row["name"], row["role"])
```

### Output

```text
Shynu Student
Alex Admin
Sam Analyst
```

`DictReader` uses the column headings as dictionary keys.

### Writing to a CSV File

```python
import csv

with open("users.csv", "w", newline="") as file:
    writer = csv.writer(file)

    writer.writerow(["name", "role"])
    writer.writerow(["Shynu", "Student"])
    writer.writerow(["Alex", "Admin"])
```

**Use cases:** Processing user lists, inventory records, security audit reports, and exported scan results.

## 🔧 4. JSON Processing

**JSON** stands for *JavaScript Object Notation*.

It is a format for storing and exchanging structured data.

### Example: `data.json`

```json
{
    "name": "Shynu",
    "age": 18,
    "role": "Cybersecurity Student"
}
```

### Reading JSON

```python
import json

with open("data.json", "r") as file:
    data = json.load(file)

print(data["name"])
print(data["role"])
```

### Output

```text
Shynu
Cybersecurity Student
```

`json.load()` reads JSON data from an open file and converts it into Python objects.

### Writing JSON

```python
import json

data = {
    "name": "Shynu",
    "age": 18,
    "role": "Cybersecurity Student"
}

with open("data.json", "w") as file:
    json.dump(data, file, indent=4)
```

`json.dump()` writes Python data into a JSON file.

### Important JSON Functions

| Function | Purpose |
|---|---|
| `json.load()` | Reads JSON from a file |
| `json.dump()` | Writes JSON to a file |
| `json.loads()` | Converts a JSON string into Python data |
| `json.dumps()` | Converts Python data into a JSON string |

### Python Dictionary vs JSON

Python dictionary:

```python
data = {"name": "Shynu", "age": 18}
```

JSON representation:

```json
{
    "name": "Shynu",
    "age": 18
}
```

**Remember:** A Python dictionary is a Python object. JSON is a data format used to store or exchange information.

**Use cases:** Configuration files, API responses, application settings, and structured security scan results.

## 🛡️ 5. Log File Handling

A **log file** records events that happen in a computer system or application.

Logs can help security analysts investigate errors, suspicious activity, and failed login attempts.

### Example: `system.log`

```text
INFO User logged in
WARNING Multiple failed login attempts
ERROR Connection failed
INFO User logged out
```

### Reading a Log File

```python
with open("system.log", "r") as file:
    for line in file:
        print(line.strip())
```

### Finding Warning Messages

```python
with open("system.log", "r") as file:
    for line in file:
        if "WARNING" in line:
            print(line.strip())
```

### Output

```text
WARNING Multiple failed login attempts
```

### Counting Warning Messages

```python
count = 0

with open("system.log", "r") as file:
    for line in file:
        if "WARNING" in line:
            count += 1

print("Total warnings:", count)
```

### Output

```text
Total warnings: 1
```

### Cybersecurity Applications

- Identifying repeated failed login attempts.
- Finding application errors.
- Reviewing authentication records.
- Investigating suspicious system activity.
- Preparing security reports.

**Important:** A warning in a log does not automatically mean an attack occurred. Investigate the surrounding events and other evidence.

## 🔒 6. File Modes

File modes control how Python opens a file.

| Mode | Read | Write | Creates Missing File | Replaces Existing Content |
|---|---|---|---|---|
| `"r"` | Yes | No | No | No |
| `"w"` | No | Yes | Yes | Yes |
| `"a"` | No | Yes | Yes | No; appends |
| `"x"` | No | Yes | Yes | No; fails if it exists |
| `"r+"` | Yes | Yes | No | No automatic truncation |

## 🧠 7. The `with` Statement

The `with` statement manages the file and closes it automatically when the block finishes, even if an error occurs during processing.

### Without `with`

```python
file = open("data.txt", "r")

content = file.read()

file.close()
```

### With `with`

```python
with open("data.txt", "r") as file:
    content = file.read()

print(content)
```

### Why Use `with`?

- Automatically closes the file.
- Reduces the chance of leaving files open.
- Makes code cleaner and easier to maintain.
- Is the recommended approach for ordinary file handling.
