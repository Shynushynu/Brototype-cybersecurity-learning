## 1. Build Python Utilities

### 🎯 Objective
Create a simple utility to validate password length.

### 💻 Code

```python
password = input("Enter your password: ")

if len(password) >= 8:
    print("Password length is valid.")
else:
    print("Password must contain at least 8 characters.")
```

### 📝 Explanation

- `input()` accepts a password from the user.
- `len()` calculates the number of characters.
- `if-else` checks whether the password contains at least eight characters.

**Note:** This checks only password length, not overall password strength.

## 2. Process Security Logs

### 🎯 Objective
Read a security log file and identify failed login attempts.

### 💻 Code

```python
with open("security.log", "r") as file:
    for line in file:
        if "failed" in line.lower():
            print(line.strip())
```

### 📄 Sample `security.log`

```text
User admin login successful
User shynu login failed
User test login failed
User admin login successful
```

### 📤 Output

```text
User shynu login failed
User test login failed
```

### 📝 Explanation

- `open()` opens the log file in read mode.
- `for` iterates through each line.
- `lower()` makes the search case-insensitive.
- `strip()` removes surrounding whitespace and newline characters.

## 3. Parse JSON Datasets

### 🎯 Objective
Read JSON data and display usernames and their roles.

### 💻 Code

```python
import json

with open("users.json", "r") as file:
    data = json.load(file)

for user in data:
    print("Username:", user["username"])
    print("Role:", user["role"])
```

### 📄 Sample `users.json`

```json
[
    {
        "username": "admin",
        "role": "administrator"
    },
    {
        "username": "shynu",
        "role": "student"
    }
]
```

### 📤 Output

```text
Username: admin
Role: administrator
Username: shynu
Role: student
```

### 📝 Explanation

- `import json` imports the JSON library.
- `json.load()` reads JSON data from a file and converts it into Python objects.
- `for` iterates through the list of dictionaries.
- Dictionary keys access the corresponding values.

## 4. Create Reusable Scripts

### 🎯 Objective
Create a reusable function that checks password length.

### 💻 Code

```python
def check_password(password):
    if len(password) >= 8:
        return "Password length is valid."
    else:
        return "Password is too short."


result = check_password("python123")
print(result)

result = check_password("abc")
print(result)
```

### 📤 Output

```text
Password length is valid.
Password is too short.
```

### 📝 Explanation

- `def` defines a function.
- `password` is a parameter that receives a value.
- `return` sends a result back to the caller.
- The same function can be reused with different inputs.

## 5. Automate Simple Security Workflows

### 🎯 Objective
Automatically count failed login attempts and generate a simple security report.

### 💻 Code

```python
failed_count = 0

with open("security.log", "r") as file:
    for line in file:
        if "failed" in line.lower():
            failed_count += 1

print("Security Report")
print("----------------")
print("Failed login attempts:", failed_count)

if failed_count > 0:
    print("Warning: Failed login attempts detected.")
else:
    print("No failed login attempts found.")
```

### 📤 Output

```text
Security Report
----------------
Failed login attempts: 2
Warning: Failed login attempts detected.
```

### 📝 Explanation

- `failed_count` stores the number of failed attempts.
- The loop reads each line in the log file.
- `failed_count += 1` increments the counter when a failed attempt is found.
- The program generates a report based on the count.
