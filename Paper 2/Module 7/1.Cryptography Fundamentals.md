## 1. What Is Cryptography?

### 📖 Definition

**Cryptography** is the technique of protecting information using mathematical algorithms and keys so that unauthorized people cannot easily understand or modify it.

It is widely used to protect passwords, online transactions, messages, files, and network communications.

### 🔑 Important Terms

| Term | Explanation |
|---|---|
| Plaintext | Original readable information |
| Ciphertext | Encrypted information |
| Encryption | Converting plaintext into ciphertext |
| Decryption | Converting ciphertext back into plaintext |
| Cryptographic key | Information used by a cryptographic algorithm |
| Cipher | An algorithm used for encryption and decryption |

### 🔄 How Cryptography Works

```text
       📝 Plaintext
          "HELLO"
             |
             v
      🔐 Encryption
       Algorithm + Key
             |
             v
       🔒 Ciphertext
       "X7A9K2"*
             |
             v
       🔓 Decryption
       Appropriate Key
             |
             v
       📝 Plaintext
          "HELLO"
```

*The ciphertext is illustrative and not the output of a real encryption algorithm.*

### 🌍 Real-World Examples

- **HTTPS:** TLS helps protect data exchanged between a browser and a website.
- **Messaging apps:** Encryption can protect message contents from unauthorized access.
- **Online banking:** Cryptographic techniques help secure transactions.
- **File protection:** Encryption helps prevent unauthorized people from reading confidential files.

### 🎤 Interview Answer

Cryptography is the science of protecting information using mathematical algorithms and keys. It helps provide confidentiality, integrity, authentication, and other security properties.

## 2. Security Goals

### 📖 Definition

Security goals are the objectives used to protect information and systems from unauthorized access, modification, disclosure, and misuse.

### 🛡️ The CIA Triad

The three fundamental information security goals are known as the **CIA Triad**.

| Goal | Meaning | Example |
|---|---|---|
| 🔒 Confidentiality | Prevent unauthorized disclosure | Encrypting a private message |
| 🛡️ Integrity | Protect against unauthorized changes | Verifying a file's hash |
| 👤 Availability | Ensure authorized users can access resources when needed | Maintaining reliable backups |

**Important:** Availability is part of the CIA Triad, but cryptography alone cannot guarantee it.

### ➕ Other Security Goals

| Goal | Purpose |
|---|---|
| Authentication | Verify identity or message origin |
| Authorization | Determine permitted actions |
| Non-repudiation | Provide evidence that helps prevent someone from denying an action |

### 🎤 Interview Answer

The CIA Triad consists of confidentiality, integrity, and availability. These goals help protect sensitive information, maintain data accuracy, and ensure that authorized users can access resources.

## 3. Confidentiality 🔒

### 📖 Definition

**Confidentiality** ensures that sensitive information is accessible only to authorized people or systems.

### ⚙️ How Is It Achieved?

- Encryption
- Access control and permissions
- Strong passwords
- Multi-factor authentication (MFA)
- Secure communication protocols

### 🌍 Real-World Example

Suppose you send a confidential message to a friend.

Without suitable protection, an attacker who intercepts the message might be able to read it. Encryption helps prevent unauthorized people from understanding its contents.

### 🔐 Types of Encryption

| Type | Explanation | Example |
|---|---|---|
| Symmetric encryption | Uses the same secret key for encryption and decryption | AES |
| Asymmetric encryption | Uses a related public and private key pair | RSA |

### 🎤 Interview Answer

Confidentiality is the protection of information from unauthorized access or disclosure. Encryption and access controls are common methods used to achieve it.

## 4. Integrity 🛡️

### 📖 Definition

**Integrity** ensures that information remains accurate and complete and that unauthorized changes can be detected or prevented.

### ⚙️ How Is It Achieved?

- Cryptographic hash functions
- Message Authentication Codes (MACs)
- Digital signatures
- File integrity monitoring
- Access controls

### 🌍 Real-World Example

Suppose you download a security tool. You calculate its SHA-256 hash and compare it with a hash obtained from a trusted source.

If both hashes match, this supports the conclusion that the file matches the trusted copy, assuming the comparison is reliable.

### 💻 Python Example: SHA-256 Hashing

```python
import hashlib

data = b"Hello World"

result = hashlib.sha256(data).hexdigest()

print(result)
```

### 🔍 Code Explanation

| Code | Purpose |
|---|---|
| `import hashlib` | Imports Python's hashing module |
| `data = b"Hello World"` | Defines the bytes to hash |
| `hashlib.sha256(data)` | Calculates the SHA-256 digest |
| `.hexdigest()` | Returns the digest as hexadecimal text |
| `print(result)` | Displays the hash |

### ⚠️ Important Note

A matching hash does not automatically prove that a file is safe. The reference hash must come from a trustworthy source.

A hash function is also **not encryption** because it is designed to produce a digest rather than recover the original data through decryption.

### 🎤 Interview Answer

Integrity ensures that information has not been changed without authorization. Hash functions, MACs, and digital signatures can help detect or prevent unauthorized modifications.

## 5. Authentication 👤

### 📖 Definition

**Authentication** is the process of verifying the identity of a user, device, or system, or verifying the origin of a message.

### 🔑 Common Authentication Methods

| Method | Example |
|---|---|
| Something you know | Password or PIN |
| Something you have | Security key or OTP device |
| Something you are | Fingerprint or face recognition |
| Digital certificates | Verifying a server's identity in TLS |

### 🌍 Real-World Example

When you log in to an email account:

1. Enter your username and password.
2. The service verifies your credentials.
3. Provide a second factor if required.
4. The service grants access if the checks succeed.

### 🔄 Authentication vs Authorization

| Authentication | Authorization |
|---|---|
| Verifies identity | Determines permissions |
| Answers: "Who are you?" | Answers: "What can you access?" |
| Example: Logging in | Example: Accessing an admin dashboard |

### 🎤 Interview Answer

Authentication verifies the identity of a user or system before access is granted. Passwords, security keys, and multi-factor authentication are common methods.

## 6. Cryptography vs Hashing 🔍

| Feature | Encryption | Hashing |
|---|---|---|
| Main purpose | Protect data confidentiality | Produce a digest for comparison and verification |
| Reversible? | Yes, with the appropriate decryption key | Designed to be one-way |
| Key required? | Depends on the encryption system | Ordinary hash functions do not require a key |
| Example | AES | SHA-256 |
| Common use | Protecting files and messages | File integrity verification |

**Remember:** Encryption protects confidentiality; hashing can help verify integrity. A plain hash alone does not authenticate the sender or guarantee that data has not been maliciously replaced.

## 8. Interview Questions 🎤

**Q1. What is cryptography?**

Cryptography protects information using mathematical algorithms and keys.

**Q2. What are the three goals of the CIA Triad?**

Confidentiality, Integrity, and Availability.

**Q3. What is the difference between encryption and decryption?**

Encryption converts readable data into ciphertext; decryption converts ciphertext back into readable data using the appropriate key.

**Q4. What is the difference between confidentiality and integrity?**

Confidentiality prevents unauthorized disclosure, while integrity protects against unauthorized modification.

**Q5. What is authentication?**

Authentication verifies the identity of a user, device, system, or the origin of a message.

**Q6. Is hashing the same as encryption?**

No. Encryption is reversible with the appropriate key, whereas a cryptographic hash function is designed to be one-way.

**Q7. What is the difference between authentication and authorization?**

Authentication verifies identity, while authorization determines which actions or resources that identity is permitted to access.
