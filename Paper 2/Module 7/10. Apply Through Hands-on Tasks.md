## 1. Analyze HTTPS Traffic

### 🎯 Objective

Understand how HTTPS protects communication between a client and a server using TLS.

### 🛠️ Tools Required

- Wireshark
- Web Browser

### Practical Steps

1. Open Wireshark.
2. Select your active network interface.
3. Start capturing network traffic.
4. Visit an HTTPS website.
5. Stop the packet capture.
6. Apply the following display filter:

```text
tls
```

7. Identify the TLS handshake packets and encrypted application data.

### Important Packets

| Packet | Purpose |
|---|---|
| Client Hello | Client initiates TLS negotiation. |
| Server Hello | Server responds with TLS parameters. |
| Certificate | Server provides its digital certificate. |
| Finished | Confirms completion of the TLS handshake. |
| Application Data | Carries encrypted application data. |

### Things to Observe

- TLS version (TLS 1.2 or TLS 1.3).
- Client Hello and Server Hello.
- Supported cipher suites.
- Server certificate information.
- Encrypted application data.

**Expected Result:** Understand how TLS establishes secure communication and protects application data.

## 2. Investigate Certificates

### 🎯 Objective

Understand how digital certificates establish server identity and trust.

### 🛠️ Tools Required

- Web Browser
- OpenSSL

### Practical Steps

**Step 1: Inspect a Website Certificate**

1. Open an HTTPS website.
2. Click the site information icon near the address bar.
3. Open the connection security or certificate information.
4. Examine the certificate details.

**Step 2: Understand Certificate Fields**

| Certificate Field | Description |
|---|---|
| Subject | Identifies the certificate owner. |
| Issuer | Certificate Authority (CA) that issued the certificate. |
| Valid From | Certificate starting date. |
| Valid To | Certificate expiration date. |
| Public Key | Public key associated with the certificate. |
| Signature Algorithm | Algorithm used to sign the certificate. |
| SAN | Subject Alternative Name; identifies covered domain names. |

**Step 3: Examine a Certificate Using OpenSSL**

```bash
openssl s_client -connect example.com:443 -servername example.com
```

### Things to Observe

- Is the certificate expired?
- Does the domain name match?
- Is the certificate issued by a trusted CA?
- Which signature algorithm is used?
- What public key algorithm is used?

**Expected Result:** Understand certificate validation and how browsers establish trust in websites.

## 3. Explore Hashing Workflows

### 🎯 Objective

Understand how hashing supports data integrity and secure password storage.

### 🛠️ Tools Required

- Python
- OpenSSL

### 3.1 Generate a SHA-256 Hash

```python
import hashlib

message = b"Hello Cybersecurity"

hash_value = hashlib.sha256(message).hexdigest()

print("SHA-256:", hash_value)
```

**Explanation:**

- `hashlib` provides hashing algorithms.
- `sha256()` generates a SHA-256 hash.
- `hexdigest()` returns the hash as a hexadecimal string.

### 3.2 Verify File Integrity

```python
import hashlib

def calculate_hash(filename):
    sha256 = hashlib.sha256()

    with open(filename, "rb") as file:
        for chunk in iter(lambda: file.read(4096), b""):
            sha256.update(chunk)

    return sha256.hexdigest()


print(calculate_hash("security.log"))
```

**Practical Steps:**

1. Generate the SHA-256 hash of a file.
2. Modify the file.
3. Generate its hash again.
4. Compare both hash values.

**Observation:** Even a small modification produces a different hash with overwhelming probability.

### 3.3 Explore Password Hashing

Understand the following concepts:

- Salt
- Password Hashing
- Rainbow Table Attacks
- Brute-Force Attacks
- Key Derivation Functions (KDF)
- PBKDF2
- bcrypt
- Argon2

**Expected Result:** Understand hashing, file integrity verification, and secure password storage.

## 4. Demonstrate Encryption Concepts

### 🎯 Objective

Understand how symmetric and asymmetric encryption protect sensitive information.

### 🛠️ Tools Required

- Python
- OpenSSL

### 4.1 Symmetric Encryption

Explore AES encryption.

**Important Concepts:**

- AES-128
- AES-192
- AES-256
- Encryption Key
- Initialization Vector (IV)
- Plaintext
- Ciphertext
- Decryption

**Key Concept:** Symmetric encryption uses the same secret key for encryption and decryption.

### 4.2 Asymmetric Encryption

Explore RSA encryption.

**Important Concepts:**

- Public Key
- Private Key
- Key Pair
- Encryption
- Decryption

**Generate an RSA Private Key:**

```bash
openssl genpkey -algorithm RSA -out private.pem -pkeyopt rsa_keygen_bits:2048
```

**Extract the Public Key:**

```bash
openssl pkey -in private.pem -pubout -out public.pem
```

### 4.3 Compare Encryption Algorithms

| Feature | Symmetric Encryption | Asymmetric Encryption |
|---|---|---|
| Keys | One shared secret key | Public and private key pair |
| Speed | Generally faster | Generally slower |
| Key Distribution | Requires secure key sharing | Public key can be shared |
| Examples | AES, ChaCha20 | RSA, ECC |
| Applications | Bulk data encryption | Key exchange and digital signatures |

**Expected Result:** Understand the differences between symmetric and asymmetric encryption and their practical applications.
