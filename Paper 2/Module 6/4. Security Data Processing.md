## 📊 1. Structured Data

Structured data is information organized in a predefined format, such as rows and columns or key-value pairs.

It makes security information easier to store, search, analyze, and process using programs.

### 💡 Example

| IP Address | Status | Event |
|---|---|---|
| `192.168.1.10` | Success | Login |
| `192.168.1.20` | Failed | Login |
| `192.168.1.30` | Success | File Access |

### 🔐 Cybersecurity Use

- Organizing login records.
- Monitoring network events.
- Analyzing security logs.
- Identifying suspicious activities.

## 📄 2. CSV Analysis

CSV stands for **Comma-Separated Values**. It is a file format used to store tabular data, where each line represents a record and commas separate individual values.

### 💡 Example: `security_logs.csv`

```csv
IP,Event,Status
192.168.1.10,Login,Success
192.168.1.20,Login,Failed
192.168.1.30,File Access,Success
```

### 🐍 Python Example

```python
import csv

with open("security_logs.csv", "r") as file:
    reader = csv.DictReader(file)

    for row in reader:
        if row["Status"] == "Failed":
            print(row)
```

### 🔍 Code Explanation

| Code | Purpose |
|---|---|
| `import csv` | Imports the CSV module |
| `open()` | Opens the CSV file |
| `csv.DictReader()` | Reads each row as a dictionary |
| `row["Status"]` | Accesses the Status value |
| `if` | Checks whether the login failed |
| `print(row)` | Displays matching records |

### 🔐 Cybersecurity Use

- Detecting failed login attempts.
- Analyzing IP addresses.
- Filtering suspicious records.
- Processing security log files.

## 🔗 3. JSON Analysis

JSON stands for **JavaScript Object Notation**. It is a lightweight data format used to store and exchange structured information using key-value pairs.

### 💡 Example: `security_data.json`

```json
{
    "ip": "192.168.1.20",
    "event": "Login",
    "status": "Failed"
}
```

### 🐍 Python Example

```python
import json

with open("security_data.json", "r") as file:
    data = json.load(file)

print(data["ip"])
print(data["status"])
```

### 🔍 Code Explanation

| Code | Purpose |
|---|---|
| `import json` | Imports the JSON module |
| `json.load(file)` | Reads JSON data from a file |
| `data["ip"]` | Accesses the IP address |
| `data["status"]` | Accesses the login status |

### 🔐 Cybersecurity Use

- Processing security tool outputs.
- Analyzing API responses.
- Reading SIEM alerts.
- Processing firewall event data.

> 💡 **Remember:** `json.load()` reads JSON from a file, while `json.loads()` reads JSON from a string.

## 🗂️ 4. Event Categorization

Event categorization is the process of grouping security events according to their type, purpose, or severity.

### 📌 Common Security Event Categories

| Category | Examples |
|---|---|
| 🔑 Authentication | Successful and failed logins |
| 🌐 Network Activity | Connections and network traffic |
| 📁 File Activity | File creation, modification, and deletion |
| ⚠️ Suspicious Activity | Unusual or potentially malicious behavior |

### 🐍 Python Example

```python
event = "Failed Login"

if event == "Failed Login":
    category = "Authentication"
elif event == "Network Connection":
    category = "Network Activity"
else:
    category = "Other"

print(category)
```

### 🔍 Output

```text
Authentication
```

### 🔐 Cybersecurity Use

- Organizing security events.
- Identifying unusual activities.
- Simplifying log analysis.
- Helping analysts investigate potential threats.

## 🚨 5. Alert Generation

Alert generation is the process of creating a notification when security data matches a predefined condition.

It helps security teams identify activities that may require investigation.

### 🐍 Python Example

```python
failed_logins = 6
threshold = 5

if failed_logins > threshold:
    print("ALERT: Multiple failed login attempts detected!")
else:
    print("No alert required.")
```

### 🔍 Output

```text
ALERT: Multiple failed login attempts detected!
```

### 🔎 Code Explanation

| Variable | Meaning |
|---|---|
| `failed_logins` | Number of failed login attempts |
| `threshold` | Configured limit |
| `if` | Checks whether the count exceeds the limit |
| `print()` | Displays the corresponding message |

### 🔐 Cybersecurity Use

- Detecting repeated failed logins.
- Highlighting suspicious network activity.
- Notifying analysts about potential threats.
- Supporting security monitoring and incident response.

> ⚠️ **Important:** An alert does not automatically confirm an attack. Analysts must investigate the event and verify the evidence.

## 🔄 Security Data Processing Workflow

```text
      📥 Security Data Collection
                 |
                 ▼
      📊 Data Analysis & Processing
                 |
                 ▼
         🗂️ Event Categorization
                 |
                 ▼
          🚨 Alert Generation
                 |
                 ▼
        🔍 Security Investigation
```

### 📝 Workflow Explanation

1. **Data Collection:** Gather information from logs, CSV files, JSON files, and security tools.
2. **Data Processing:** Read, filter, and analyze the collected information.
3. **Event Categorization:** Group events according to their types and characteristics.
4. **Alert Generation:** Create alerts when predefined conditions are met.
5. **Security Investigation:** Review alerts and determine whether further action is needed.
