# 🖥️ 5. Understand Monitoring Automation

## 📌 Overview

Monitoring automation is the process of using scripts, programs, and tools to continuously monitor a computer system, services, files, and system activities. It helps identify problems, detect unexpected changes, and generate alerts automatically without requiring constant manual supervision.

In cybersecurity, monitoring automation helps detect suspicious activities, identify system failures, and respond to potential security threats quickly.

## 🖥️ 1. System Monitoring

### 📖 What is System Monitoring?

System monitoring is the process of continuously checking a computer's performance, resource usage, and overall health to ensure that it operates properly.

It helps identify performance problems, resource shortages, and unusual system activity.

### 🔹 What Can We Monitor?

- **CPU Usage:** Measures how much processing power the system is using.
- **Memory Usage:** Tracks how much RAM is being used by running programs.
- **Disk Usage:** Checks available storage space and identifies disks that are nearly full.
- **Network Activity:** Monitors network traffic, connections, and data transfer.
- **System Uptime:** Measures how long the computer has been running.

### 🛠️ Example

Suppose a computer's CPU usage suddenly reaches 95%. An automated monitoring script can detect this high usage and generate an alert so that the administrator can investigate the cause.

### 🔐 Cybersecurity Application

System monitoring can help identify unusual resource consumption caused by suspicious processes, unauthorized programs, or potential malware activity.

### 🐍 Python Example

```python
import psutil

cpu_usage = psutil.cpu_percent(interval=1)
memory_usage = psutil.virtual_memory().percent
disk_usage = psutil.disk_usage("/").percent

print("CPU Usage:", cpu_usage, "%")
print("Memory Usage:", memory_usage, "%")
print("Disk Usage:", disk_usage, "%")

if cpu_usage > 80:
    print("ALERT: High CPU usage detected!")
```

**Explanation:**

- `psutil.cpu_percent(interval=1)` measures CPU usage over one second.
- `psutil.virtual_memory().percent` returns the percentage of RAM in use.
- `psutil.disk_usage("/").percent` checks disk usage for the specified filesystem.
- The `if` statement generates an alert when CPU usage exceeds 80%.

**Note:** Install the required library using `pip install psutil`. On Windows, use `psutil.disk_usage("C:\\")` to check the C drive.

## ⚙️ 2. Service Monitoring

### 📖 What is Service Monitoring?

Service monitoring is the process of checking whether important system services and applications are running correctly and responding as expected.

A service is a background program that performs a specific function, such as providing web pages, managing databases, or handling network connections.

### 🔹 Examples of Services to Monitor

- **Web Server:** Checks whether a website's server is running.
- **SSH Service:** Checks whether the Secure Shell service is available.
- **Database Service:** Ensures that the database is running and accessible.
- **DNS Service:** Checks whether domain name resolution is functioning.
- **Security Services:** Monitors important security-related background processes.

### 🛠️ Example

Suppose a web server stops working unexpectedly. An automated monitoring system can detect that the service is unavailable and notify the administrator.

Depending on its configuration and permissions, the system may also attempt to restart the service.

### 🔐 Cybersecurity Application

Service monitoring helps detect unexpected service failures, unauthorized service changes, and the unavailability of critical security tools.

### 💻 Linux Example

```bash
systemctl is-active ssh
```

**Explanation:**

- `systemctl` manages and checks systemd services.
- `is-active` checks whether a service is currently active.
- `ssh` specifies the service to check.

If the service is active, the command normally returns `active`. Service names may differ between Linux distributions.

## 📁 3. File Monitoring

### 📖 What is File Monitoring?

File monitoring is the process of observing files and directories to identify activities such as creation, modification, deletion, or access.

It is useful for protecting important files and detecting unexpected changes to system configurations, application files, and security logs.

### 🔹 What Can We Monitor?

- **File Creation:** Detects when a new file appears.
- **File Modification:** Identifies changes made to an existing file.
- **File Deletion:** Detects when a file is removed.
- **File Access:** Tracks access events when the operating system and monitoring tools provide that information.
- **File Integrity:** Checks whether a file's contents have changed.

### 🛠️ Example

Suppose a configuration file contains important security settings. If someone modifies that file unexpectedly, a monitoring script can detect the change and generate an alert.

### 🔐 Cybersecurity Application

File monitoring helps identify suspicious modifications to configuration files, critical system files, and important application data.

### 🐍 Python Example

```python
import os

file_path = "security_config.txt"

if os.path.exists(file_path):
    print("File exists.")
else:
    print("ALERT: File is missing!")
```

**Explanation:**

- `os.path.exists(file_path)` checks whether the specified path exists.
- If the file exists, the program reports its presence.
- Otherwise, it generates an alert that the file is missing.

**Important:** This example checks file existence only. Detecting changes to file contents requires additional techniques, such as comparing file hashes or recording modification times.

## 🔍 4. Change Detection

### 📖 What is Change Detection?

Change detection is the process of identifying differences between a system's current state and its previously recorded state.

It helps detect unexpected changes to files, configurations, services, permissions, and other monitored resources.

File monitoring focuses on observing file activity, while change detection compares states or values to determine what has changed.

### 🔹 Types of Changes That Can Be Detected

- **File Changes:** Detects modifications to file contents.
- **Configuration Changes:** Identifies changes to system settings.
- **Permission Changes:** Detects changes in file or directory permissions.
- **Service Changes:** Identifies unexpected changes in service status or configuration.
- **System Changes:** Detects changes in selected system properties.

### 🛠️ Example: File Integrity Using Hashes

A cryptographic hash creates a fixed-length value representing the contents of a file. By comparing the current hash with a previously saved hash, a program can detect whether the file's contents have changed.

```python
import hashlib

def calculate_hash(file_path):
    sha256 = hashlib.sha256()

    with open(file_path, "rb") as file:
        for chunk in iter(lambda: file.read(4096), b""):
            sha256.update(chunk)

    return sha256.hexdigest()

print(calculate_hash("security_config.txt"))
```

**Explanation:**

- `hashlib.sha256()` creates a SHA-256 hash object.
- `"rb"` opens the file in binary mode.
- `file.read(4096)` reads the file in small chunks.
- `sha256.update(chunk)` adds each chunk to the hash calculation.
- `hexdigest()` returns the final hash as a hexadecimal string.

**Important:** This code calculates a hash but does not detect changes by itself. To detect changes, compare the result against a trusted hash recorded earlier. The original hash must be protected so an attacker cannot silently replace both the file and its reference hash.

### 🔐 Cybersecurity Application

Change detection is commonly used in file integrity monitoring, configuration monitoring, and the investigation of suspicious system modifications.

## 🚨 5. Alerting Workflows

### 📖 What is an Alerting Workflow?

An alerting workflow is a sequence of automated steps that identifies an event, evaluates whether it meets a defined condition, and notifies the appropriate person or system.

It allows administrators and security teams to respond to important events without continuously watching monitoring dashboards.

### 🔹 Main Steps in an Alerting Workflow

1. **Data Collection:** Collect information from system metrics, logs, files, or services.
2. **Condition Checking:** Compare the collected information against predefined rules.
3. **Event Detection:** Identify an event that requires attention.
4. **Alert Generation:** Create a warning or notification.
5. **Notification:** Send the alert through a configured channel.
6. **Response:** Investigate the event and take appropriate action.

### 🛠️ Example

Imagine that an automated script monitors CPU usage every minute.

- If CPU usage remains normal, monitoring continues.
- If CPU usage exceeds the defined threshold, the script generates an alert.
- The alert is written to a log file or sent to a configured notification service.
- The administrator investigates the cause.

### 🐍 Python Example

```python
cpu_usage = 92

if cpu_usage > 80:
    alert_message = "ALERT: High CPU usage detected!"
    print(alert_message)

    with open("monitoring_alerts.log", "a") as log_file:
        log_file.write(alert_message + "\n")
```

**Explanation:**

- `cpu_usage = 92` represents an example CPU reading.
- The `if` statement checks whether usage exceeds 80%.
- `print()` displays the alert.
- Opening the file with `"a"` appends the alert to the log instead of overwriting previous entries.

**Note:** This is a basic demonstration using a fixed example value. A real monitoring workflow would collect live metrics, evaluate the condition repeatedly, and configure an appropriate notification channel.

### 🔐 Cybersecurity Application

Alerting workflows help security teams identify suspicious login attempts, unusual network activity, critical service failures, and unexpected file changes.

## 🔄 How Monitoring Automation Works

A typical monitoring automation process follows this sequence:

**Collect Data → Analyze Data → Check Conditions → Detect Events → Generate Alerts → Take Action**

For example, a monitoring script collects system metrics, detects unusual CPU usage, checks whether the value exceeds a threshold, and generates an alert when the condition is met.

## 🛡️ Benefits of Monitoring Automation

- **Early Detection:** Identifies potential problems before they become serious.
- **Reduced Manual Work:** Automates repetitive monitoring tasks.
- **Faster Response:** Notifies administrators when important events occur.
- **Improved Security:** Helps identify suspicious activity and unexpected changes.
- **Continuous Monitoring:** Checks systems regularly without requiring constant manual supervision.
- **Better Reporting:** Records alerts and events for later investigation.
