# 🌐 4. Understand HTTP Fundamentals

## 📌 Introduction

**HTTP (Hypertext Transfer Protocol)** is a communication protocol used to transfer data between a client (usually a web browser) and a web server.

It defines how a client sends requests to a server and how the server responds.

For example, when you open Facebook:

1. Your browser sends an HTTP request to Facebook's server.
2. The server processes the request.
3. The server sends an HTTP response.
4. Your browser displays the webpage.

## 1. 📩 HTTP Requests

An **HTTP request** is a message sent by a client to a web server asking for a resource or requesting an action.

**Example:**

When you open `www.facebook.com`, your browser sends a request to Facebook's server to retrieve the webpage.

An HTTP request generally contains:

- **Method:** Specifies what action the client wants.
- **URL:** Identifies the requested resource.
- **Headers:** Provide additional information about the request.
- **Body:** Contains data sent to the server (mainly with POST and other methods).

---

## 2. 📤 HTTP Responses

An **HTTP response** is a message sent by the server back to the client after processing a request.

For example, when you request a webpage, the server sends the requested HTML document.

An HTTP response generally contains:

- **Status Code:** Indicates the result of the request.
- **Headers:** Provide additional information about the response.
- **Body:** Contains the requested content, such as HTML, JSON, images, or other data.

---

## 3. 🔧 HTTP Methods

HTTP methods define what action the client wants the server to perform.

| Method | Purpose | Example |
|---|---|---|
| GET | Retrieve data | View a webpage |
| POST | Send new data | Create an account |
| PUT | Replace existing data | Update a user profile |
| PATCH | Partially update data | Change username |
| DELETE | Delete data | Delete an account |
| HEAD | Retrieve headers only | Check resource information |
| OPTIONS | Check supported methods | Check server capabilities |

**Example:**

```http
GET /products HTTP/1.1
Host: example.com
```

This request asks the server to retrieve the `/products` resource.

---

## 4. 🚦 HTTP Status Codes

HTTP status codes are three-digit numbers returned by the server to indicate the result of a request.

There are five main categories:

| Code Range | Category | Meaning |
|---|---|---|
| 1xx | Informational | Request processing continues |
| 2xx | Success | Request completed successfully |
| 3xx | Redirection | Further action is needed |
| 4xx | Client Error | Problem with the request |
| 5xx | Server Error | Problem on the server |

**Important HTTP Status Codes:**

| Status Code | Meaning |
|---|---|
| 200 | OK – Request successful |
| 201 | Created – Resource created |
| 301 | Moved Permanently |
| 302 | Found – Temporary redirection |
| 400 | Bad Request |
| 401 | Unauthorized – Authentication required |
| 403 | Forbidden – Access denied |
| 404 | Not Found |
| 405 | Method Not Allowed |
| 500 | Internal Server Error |
| 502 | Bad Gateway |
| 503 | Service Unavailable |

---

## 5. 📋 HTTP Headers

**HTTP headers** are additional pieces of information included in HTTP requests and responses.

They help the client and server exchange information about the data being transferred.

There are two main types:

### A. Request Headers

Sent by the client to provide information about the request.

| Header | Purpose |
|---|---|
| Host | Specifies the target domain |
| User-Agent | Identifies the client or browser |
| Accept | Specifies acceptable response formats |
| Authorization | Carries authentication credentials or tokens |
| Content-Type | Specifies the format of the request body |
| Cookie | Sends stored cookies to the server |

### B. Response Headers

Sent by the server to provide information about the response.

| Header | Purpose |
|---|---|
| Content-Type | Specifies the response data format |
| Content-Length | Indicates the response body size |
| Set-Cookie | Instructs the browser to store a cookie |
| Cache-Control | Defines caching rules |
| Server | Provides information about server software |
| Location | Specifies a redirection destination |

---

## 🔐 HTTP and Cybersecurity

Understanding HTTP is important in cybersecurity because web applications communicate using HTTP or HTTPS.

Some security-related areas include:

- **HTTPS:** Protects HTTP communication using TLS encryption.
- **Cookies:** Help maintain user sessions.
- **Authentication:** Verifies user identity.
- **HTTP Headers:** Can provide important security protections.
- **Web Attacks:** Understanding HTTP helps explain vulnerabilities such as Cross-Site Scripting (XSS), SQL Injection, and CSRF.

## 🎯 Quick Summary

| Topic | Key Point |
|---|---|
| Requests | Client sends messages to the server |
| Responses | Server replies to the client |
| Methods | Define the requested action |
| Status Codes | Indicate the result of a request |
| Headers | Carry additional information |

**Remember:** HTTP follows a request-response model. The client sends a request, and the server returns a response.
