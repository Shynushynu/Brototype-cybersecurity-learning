# 1. How Websites Work

A **website** is a collection of web pages that users can access through a web browser using the internet.

**Examples:**
- Facebook
- Google
- YouTube
- Amazon

### ⚙️ How Does a Website Work?

When you enter `www.facebook.com` in your browser, several processes happen.

1. **User Request:** You enter a website address in your browser.
2. **DNS Resolution:** DNS converts the domain name into an IP address.
3. **Server Connection:** Your browser connects to the website's server.
4. **Server Processing:** The server processes your request.
5. **Response:** The server sends the required data to your browser.
6. **Rendering:** Your browser displays the website.

### 🔄 Website Working Process

`User → Browser → DNS → Web Server → Response → Browser`

### 💡 Example

When you open YouTube, your browser requests the website, the server processes the request, and your browser displays the YouTube homepage.

# 2. Client-Server Architecture

**Client-server architecture** is a computing model in which two main components communicate with each other.

### 🖥️ Main Components

- **Client:** Requests services or resources.
- **Server:** Receives requests, processes them, and sends responses.

### 📌 Example: Facebook Login

1. You enter your email and password.
2. Your browser sends the login request to Facebook's server.
3. The server checks the credentials.
4. The server sends a response.
5. Your browser displays the result.

### 📚 Important Terminologies

| Term | Meaning |
|---|---|
| Client | Device or application making a request |
| Server | System that provides services |
| Request | Message sent by the client |
| Response | Message sent by the server |
| Protocol | Rules used for communication |
| HTTP/HTTPS | Protocols used for web communication |

# 3. Frontend and Backend Concepts

Web applications are generally divided into two major parts.

## 🎨 Frontend

Frontend is the part of a website that users can see and interact with.

**Technologies:**

- HTML – Creates the structure.
- CSS – Controls appearance and styling.
- JavaScript – Adds functionality and interactivity.

**Examples:** Login forms, buttons, images and navigation menus.

## ⚙️ Backend

Backend is the server-side part of a website that handles processing, business logic, authentication and data management.

**Common Technologies:**

- Python
- Java
- PHP
- Node.js

## 🗄️ Database

A database stores and manages website information.

**Examples:**
- MySQL
- PostgreSQL
- MongoDB

### 📌 Example: Facebook Login

| Component | Responsibility |
|---|---|
| Frontend | Displays the login form |
| Backend | Processes login requests |
| Database | Stores user account information |

# 4. Web Application Workflows

A **web application workflow** describes how information moves between the user, frontend, backend and database to complete an operation.

### 🔄 Example: Creating a Facebook Account

1. User opens the registration page.
2. Frontend displays the registration form.
3. User enters their details.
4. Frontend sends the information to the backend.
5. Backend validates the submitted information.
6. Backend securely stores the account information in the database.
7. Server sends a response to the frontend.
8. Frontend displays the result.

### 📌 Common Web Application Workflows

- User Registration
- User Authentication
- Login and Logout
- Searching Information
- Uploading Files
- Retrieving Information

# 5. Modern Web Architecture

**Modern web architecture** describes how today's web applications are designed using different technologies and services to provide better performance, scalability and security.

## 5.1 Three-Tier Architecture

Divides an application into three layers.

| Layer | Responsibility |
|---|---|
| Presentation Layer | User interface (Frontend) |
| Application Layer | Business logic (Backend) |
| Data Layer | Stores information (Database) |

## 5.2 API (Application Programming Interface)

An API allows different applications or systems to communicate with each other.

**Example:** A weather application uses a weather API to retrieve weather information from a server.

## 5.3 Cloud Computing

Cloud computing allows applications and data to be hosted on remote servers instead of relying only on local computers.

**Examples:**
- AWS
- Microsoft Azure
- Google Cloud

## 5.4 Microservices Architecture

An application is divided into smaller independent services, where each service handles a specific function.

**Example:** An e-commerce application might have separate services for:

- User Management
- Payments
- Product Management
- Orders

## 5.5 Content Delivery Network (CDN)

A CDN uses distributed servers to deliver website content from locations closer to users, improving loading speed.

# 🛡️ Cybersecurity Connection

Understanding web fundamentals is important in cybersecurity because:

| Component | Security Concern |
|---|---|
| Frontend | User input vulnerabilities |
| Backend | Server-side vulnerabilities |
| Database | Unauthorized data access |
| Network | Interception of communication |
| Authentication | Unauthorized account access |

These concepts will help when learning:

- HTTP Request and Response
- HTTPS and TLS
- Authentication and Authorization
- SQL Injection
- Cross-Site Scripting (XSS)
- Web Application Security
