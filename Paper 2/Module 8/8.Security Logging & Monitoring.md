# 🔐 8. Understand Security Logging & Monitoring

> **Paper 2 · Module 4 · Web & Security Fundamentals**

## 📌 Overview

**Security Logging & Monitoring** is the process of recording, collecting, and analyzing activities happening inside a web application or server to identify errors, suspicious activities, and potential security threats.

It helps administrators and security teams understand what is happening in their systems and detect unusual behaviour.

## 1. 📝 Application Logs

Application logs record activities and events happening inside an application.

They help developers understand how an application works and identify problems.

### Examples

- User registration.
- User login and logout.
- File uploads.
- API requests.
- Application activities.

### Example Log

```text
2026-11-09 10:30:15 INFO User registered successfully
2026-11-09 10:32:20 INFO User logged in
2026-11-09 10:35:10 INFO File uploaded successfully
```

### 🎯 Purpose

- Track application activities.
- Understand application behaviour.
- Troubleshoot application problems.

---

## 2. 🌐 Access Logs

Access logs record requests received by a web server from clients (browsers, applications, etc.).

They help administrators understand who accessed the server and what resources they requested.

### Examples

- Client IP address.
- Requested URL.
- HTTP method (GET, POST).
- HTTP status code.
- Request timestamp.

### Example Log

```text
192.168.1.10 - - [09/Nov/2026:10:30:15]
"GET /index.html HTTP/1.1" 200
```

### Understanding the Log

| Value | Meaning |
|---|---|
| `192.168.1.10` | Client IP address |
| `GET` | HTTP method |
| `/index.html` | Requested resource |
| `200` | Successful response |

### 🎯 Purpose

- Track incoming requests.
- Monitor website traffic.
- Identify unusual access patterns.

---

## 3. ⚠️ Error Logs

Error logs record problems that occur inside an application or server.

They help developers identify and troubleshoot technical issues.

### Examples

- Database connection failures.
- Internal server errors.
- Application crashes.
- Failed API operations.
- Missing files.

### Example Log

```text
2026-11-09 10:40:15 ERROR Database connection failed
2026-11-09 10:42:20 ERROR Internal Server Error (500)
```

### 🎯 Purpose

- Identify application errors.
- Troubleshoot server problems.
- Understand why operations fail.

---

## 4. 📋 Audit Trails

An audit trail is a chronological record of important activities performed by users or administrators in a system.

It helps track **who performed an action, what action was performed, and when it happened.**

### Examples

- Administrator changed user permissions.
- User updated account information.
- Someone deleted a database record.
- Password or security settings were changed.

### Example

| User | Activity | Time |
|---|---|---|
| Admin | Changed user role | 10:30 AM |
| User01 | Updated profile | 10:35 AM |
| Admin | Deleted an account | 10:40 AM |

### 🎯 Purpose

- Investigate security incidents.
- Track unauthorized changes.
- Maintain accountability.
- Support compliance and auditing.

---

## 5. 👁️ Security Visibility

Security visibility means having a clear understanding of activities, events, and potential threats happening across an organization's systems.

It is achieved by collecting and analyzing logs from different sources.

### Examples

- Detecting repeated failed login attempts.
- Identifying unusual API requests.
- Monitoring suspicious IP addresses.
- Detecting unexpected administrator activities.
- Identifying unusual network traffic.

### Popular Security Monitoring Tools

| Tool | Purpose |
|---|---|
| **Splunk** | Log analysis and monitoring |
| **Wazuh** | Security monitoring and threat detection |
| **Elastic Stack** | Log collection and visualization |

### 🎯 Purpose

- Detect security threats.
- Monitor system activities.
- Identify suspicious behaviour.
- Improve security awareness.

---

## 🔄 How They Work Together

Imagine someone trying to access an account using an incorrect password multiple times.

1. **👤 User attempts to log in**
   - Multiple incorrect passwords are entered.

2. **📝 Logs record the activity**
   - Application logs and access logs record the login attempts.

3. **🔎 Monitoring system analyzes logs**
   - Identifies repeated failed login attempts.

4. **🚨 Security alert generated**
   - Administrator investigates the suspicious activity.

## 📊 Important Differences

| Type | Main Purpose |
|---|---|
| 📝 Application Logs | Record application activities |
| 🌐 Access Logs | Record client requests |
| ⚠️ Error Logs | Record application/server errors |
| 📋 Audit Trails | Track important user actions |
| 👁️ Security Visibility | Understand and monitor security activities |

---

## 🛡️ Cybersecurity Importance

Security Logging & Monitoring helps organizations:

1. 🔍 Detect suspicious activities.
2. 🚨 Investigate security incidents.
3. 🔐 Identify unauthorized access.
4. 🛠️ Troubleshoot application problems.
5. 📋 Maintain accountability.
6. 🛡️ Improve overall security.

---

## 💡 Key Takeaway

> **Remember these two concepts:**

- 📝 **Logging:** Records what happened.
- 👁️ **Monitoring:** Analyzes activities to identify what is happening and detect potential problems.

Together, they help organizations maintain security and visibility over their systems.
