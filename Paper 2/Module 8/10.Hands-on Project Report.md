# 🧮 JavaScript Square Calculator – Hands-on Project Report

## 📌 1. Project Overview

The JavaScript Square Calculator is a simple web application that accepts a number from the user and calculates its square.

The application is developed using:
- HTML – Webpage structure
- CSS – Styling and design
- JavaScript – Calculation and functionality

## 🎯 2. Build a Simple Web Application

### Features
1. Accepts a number from the user.
2. Calculates the square using JavaScript.
3. Displays the calculated result.
4. Uses a read-only input field to display the output.
5. Provides CSS styling for a better user interface.

### Working Process

1. The user enters a number.
2. The user clicks the **Show** button.
3. The JavaScript `showSquare()` function executes.
4. The entered number is multiplied by itself.
5. The result is displayed in the output field.

### Code Used

```javascript
function showSquare()
{
    var num, ans;
    num = document.formSquare.txtNum.value;
    ans = num * num;
    document.formSquare.txtSquare.value = ans;
}
```

## 🔐 4. Identify Security Weaknesses

### Observed Security Considerations

| Area | Observation | Suggested Improvement |
|---|---|---|
| Input validation | Accepts text input without explicit validation | Validate numeric input |
| Error handling | No error handling is implemented | Handle invalid values |
| Client-side processing | Calculation happens in the browser | Do not rely on client-side checks for sensitive operations |
| Logging | No application logs | Add basic activity logging |

### Important Note

This is a basic calculator, so it does not process sensitive information or communicate with a backend server.

## 📝 5. Create Secure Development Report

### Project Summary

The JavaScript Square Calculator demonstrates basic web application development using HTML, CSS and JavaScript.

### Security Findings

1. Input validation should be improved.
2. Invalid input should be handled properly.
3. Application activity is not currently recorded.
4. Error handling can be added to improve reliability.

### Recommended Improvements

- Validate user input before calculation.
- Accept only valid numeric values.
- Display a clear message for invalid input.
- Introduce basic logging if activity tracking is required.

This project helped demonstrate how HTML, CSS and JavaScript work together to create a simple web application. It also provided an opportunity to understand basic input validation, error handling, application logging and secure development practices.
