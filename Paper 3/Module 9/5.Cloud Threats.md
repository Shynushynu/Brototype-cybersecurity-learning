# ☁️ 5. Understand Cloud Threats

> 💡 **Overview:** Cloud threats are security risks that can affect cloud-based systems, applications, and data. These threats may occur due to improper configurations, stolen credentials, excessive permissions, or malicious activities.

## ⚙️ 1. Misconfigurations

**Misconfiguration** occurs when cloud resources are set up incorrectly, creating security vulnerabilities.

- 📝 **Example:** An AWS S3 bucket is accidentally configured to allow public access.
- ⚠️ **Risk:** Unauthorized people may access sensitive data.
- 🛡️ **Prevention:** Follow secure configuration practices and regularly review cloud settings.

## 🔑 2. Credential Theft

**Credential theft** occurs when attackers steal login credentials such as usernames, passwords, or access keys to gain unauthorized access to cloud accounts.

- 📝 **Example:** An attacker steals an employee's AWS login credentials through a phishing email.
- ⚠️ **Risk:** Attackers may gain access to cloud resources and sensitive information.
- 🛡️ **Prevention:** Use Multi-Factor Authentication (MFA), strong passwords, and secure credential storage.

## 🔓 3. Excessive Permissions

**Excessive permissions** occur when users or applications are given more access privileges than they actually need.

- 📝 **Example:** A developer is given administrator access even though they only need permission to view files in an S3 bucket.
- ⚠️ **Risk:** If the account is compromised, attackers may gain unnecessary control over cloud resources.
- 🛡️ **Prevention:** Follow the **Principle of Least Privilege (PoLP)** by granting only the permissions required.

## 📂 4. Data Exposure

**Data exposure** occurs when sensitive information becomes accessible to unauthorized people due to security weaknesses.

- 📝 **Example:** Customer information is accidentally exposed through a publicly accessible cloud storage service.
- ⚠️ **Risk:** Data leakage, privacy violations, and financial damage.
- 🛡️ **Prevention:** Use encryption, access controls, and proper data protection policies.

## 👤 5. Insider Threats

**Insider threats** occur when someone within an organization, such as an employee or contractor, misuses their authorized access, intentionally or accidentally.

- 📝 **Example:** An employee accidentally shares confidential company data with unauthorized people.
- ⚠️ **Risk:** Sensitive information may be leaked, modified, or misused.
- 🛡️ **Prevention:** Monitor user activities, apply access restrictions, and conduct regular security audits.

## 🎯 Important Interview Questions

**1. What is a cloud misconfiguration?**

A cloud misconfiguration occurs when cloud resources are incorrectly configured, potentially exposing systems or data to security risks.

**2. What is the Principle of Least Privilege?**

It is a security principle that ensures users receive only the minimum permissions required to perform their tasks.

**3. What is an insider threat?**

An insider threat is a security risk caused by someone within an organization who misuses their authorized access, either intentionally or accidentally.

**4. What is the difference between credential theft and excessive permissions?**

- 🔑 **Credential theft:** An attacker obtains someone else's login credentials.
- 🔓 **Excessive permissions:** A user or application already has more access privileges than necessary.
