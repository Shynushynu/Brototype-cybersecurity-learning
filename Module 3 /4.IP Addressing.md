> 🔐 **IP Addressing** is a fundamental networking concept used to **identify devices and networks** and determine where data should be delivered.

# 🔹 a. IPv4

**IPv4 (Internet Protocol version 4)** is the most commonly used IP addressing system.

### 📌 Key Features

| Feature         | Description         |
| --------------- | ------------------- |
| 🔢 Address Size | **32 bits**         |
| ✍️ Format       | Decimal             |
| 🔗 Sections     | 4 octets            |
| 📏 Range        | `0 – 255` per octet |
| 📝 Example      | `192.168.1.10`      |

### 🧩 IPv4 Structure

```text
192 . 168 . 1 . 10
 │     │     │    │
 └─────┴─────┴────┘
       32 bits
```

Each section contains **8 bits**:

```text
8 bits + 8 bits + 8 bits + 8 bits = 32 bits
```

### 💡 Example

```text
IP Address: 192.168.1.10

Network → 192.168.1
Host    → 10
```

> 🛡️ **Cybersecurity Note:** IPv4 addresses are commonly used when identifying hosts during network monitoring, asset discovery, and security analysis.

---

# 🔹 b. IPv6

**IPv6 (Internet Protocol version 6)** was introduced to overcome the limited address space of IPv4.

### 📌 Key Features

| Feature          | Description                      |
| ---------------- | -------------------------------- |
| 🔢 Address Size  | **128 bits**                     |
| ✍️ Format        | Hexadecimal                      |
| 🔗 Sections      | 8 groups                         |
| 📝 Example       | `2001:0db8:85a3::8a2e:0370:7334` |
| 🌍 Address Space | Extremely large                  |

### 🧩 IPv6 Example

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

IPv6 can use `::` to represent consecutive groups of zeros.

Example:

```text
2001:0db8:0000:0000:0000:0000:0000:0001

↓ shortened

2001:db8::1
```

### ⚡ IPv4 vs IPv6

| Feature          | IPv4           | IPv6            |
| ---------------- | -------------- | --------------- |
| 🔢 Address Size  | 32-bit         | 128-bit         |
| 🔤 Format        | Decimal        | Hexadecimal     |
| 🌐 Example       | `192.168.1.10` | `2001:db8::1`   |
| 📦 Address Space | Limited        | Extremely large |
| 📡 Broadcast     | Supported      | Not used        |

---

# 🔹 c. Public IP Addresses 🌍

A **Public IP address** is an IP address used for communication over the **Internet**.

It is generally assigned to a network's Internet connection by an **Internet Service Provider (ISP)**.

### 🌐 Basic Flow

```text
             🌍 Internet
                  │
                  ↓
            📡 Public IP
                  │
                  ↓
              🛜 Router
                  │
          ┌───────┼───────┐
          ↓       ↓       ↓
        💻 PC   📱 Phone  🖨️ Printer
```

### 📌 Key Points

* 🌍 Used for Internet communication
* 🔢 Globally unique
* 🏢 Usually assigned by an ISP
* 🔄 Can be associated with a router or network connection

> 🔐 **Cybersecurity Note:** Public IP addresses can be observed during network communication and may be relevant to security monitoring and incident investigation.

---

# 🔹 d. Private IP Addresses 🏠

A **Private IP address** is used inside a **local network**, such as:

* 🏠 Home networks
* 🏢 Company networks
* 🏫 School networks
* 🧪 Laboratory networks

### 📋 Private IPv4 Ranges

| Private Range                   | CIDR  |
| ------------------------------- | ----- |
| `10.0.0.0 – 10.255.255.255`     | `/8`  |
| `172.16.0.0 – 172.31.255.255`   | `/12` |
| `192.168.0.0 – 192.168.255.255` | `/16` |

### 🏠 Example

```text
              🛜 Router
            Public IP
                 │
        ┌────────┼────────┐
        ↓        ↓        ↓
      💻 PC    📱 Phone  🖨️ Printer
 192.168.1.10  .11       .12
```

Private IPv4 addresses are **not directly routable on the public Internet**.

A router commonly uses **NAT (Network Address Translation)** so devices with private addresses can communicate with the Internet through a public IP.

# 🔹 e. Subnetting Fundamentals 🧩

> 💡 **Subnetting** is the process of dividing a larger network into **smaller logical networks called subnets**.

### 🎯 Why Use Subnetting?

* 📦 Efficient IP address usage
* 🏢 Organize large networks
* 🚦 Reduce broadcast traffic
* 🔐 Improve network segmentation
* 🛡️ Help isolate different systems

---

## 🧮 Example: `/24` Network

Consider:

```text
192.168.1.0/24
```

A `/24` network contains:

```text
256 total addresses
```

It can be divided into four `/26` subnets:

```text
┌───────────────────────────────┐
│       192.168.1.0/24          │
└───────────────────────────────┘
              │
      ┌───────┼───────┐
      ↓       ↓       ↓       ↓
    /26     /26      /26     /26

192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26
```

Each `/26` subnet contains **64 total addresses**.

---

# 🧠 Important Subnetting Terms

| Term                   | Meaning                                |
| ---------------------- | -------------------------------------- |
| 🌐 **IP Address**      | Identifies a network interface         |
| 🏠 **Network Address** | Identifies the network                 |
| 💻 **Host Address**    | Identifies a device within the network |
| 🎭 **Subnet Mask**     | Separates network and host portions    |
| 📐 **CIDR**            | Notation such as `/24` or `/26`        |
| 🧩 **Subnet**          | A smaller logical network              |
