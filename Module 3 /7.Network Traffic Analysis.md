# 🌐 7. Understand Network Traffic Analysis

> 🛡️ **Network Traffic Analysis** is the process of monitoring, examining, and understanding network communication to identify normal activity, suspicious behavior, and potential security threats.

# 📦 A. Packets

A **packet** is a small unit of data sent across a network.

When a large amount of data is transmitted, it is divided into smaller pieces called **packets**.

### 🧩 A Packet Can Contain

| Component             | Meaning                                   |
| --------------------- | ----------------------------------------- |
| 📍 **Source IP**      | Device that sent the packet               |
| 🎯 **Destination IP** | Device receiving the packet               |
| 🔌 **Protocol**       | Communication protocol such as TCP or UDP |
| 🚪 **Port**           | Identifies the service or application     |
| 📦 **Payload**        | Data being carried                        |

### 💡 Example

```text
💻 Computer
    │
    │  📦 Packet
    ▼
🌐 Web Server
```

When you open a website, your device sends and receives many packets between itself and the web server.

---

# 🌊 B. Traffic Flows

A **traffic flow** is a series of packets exchanged between devices during a communication session.

Traffic flows help analysts understand **who is communicating with whom and how**.

### 🔍 A Traffic Flow Can Show

* 📍 Source IP address
* 🎯 Destination IP address
* 🚪 Source and destination ports
* 🔌 Protocol
* 📊 Amount of data transferred
* ⏱️ Communication duration

### 💡 Example

```text
💻 Computer
192.168.1.10:51520
        │
        │ HTTPS / TCP
        ▼
🌐 Web Server
142.250.x.x:443
```

> 🔎 By analyzing traffic flows, security analysts can identify unusual or unexpected communication.

# 👁️ C. Network Visibility

**Network visibility** means being able to see and understand **what is happening on a network.**

### 🔍 Sources of Network Visibility

```text
        🌐 NETWORK
            │
   ┌────────┼────────┐
   ▼        ▼        ▼
🔥 Firewall 📡 IDS/IPS 📝 Logs
   │        │        │
   └────────┼────────┘
            ▼
      👁️ Visibility
```

Security teams can gain visibility through:

* 🔍 Packet captures
* 📊 Flow data
* 📝 Network logs
* 🔥 Firewalls
* 🚨 IDS/IPS
* 📡 Network monitoring tools

### 🎯 Why It Matters

Good network visibility helps security teams detect:

* 🚫 Unauthorized devices
* 🔗 Suspicious connections
* 📈 Unusual traffic
* 🦠 Possible malware activity
* ⚠️ Potential attacks

# 📝 D. Log Generation

**Log generation** means creating a record of activities happening on a **network**(also work for **computer and application**)

Network devices and security tools can automatically generate logs when different activities occur.

### 📋 Common Log Information

| Information       | Example                  |
| ----------------- | ------------------------ |
| 🕐 Timestamp      | `10:32:15`               |
| 📍 Source IP      | `192.168.1.20`           |
| 🎯 Destination IP | `203.0.113.10`           |
| 🚪 Port           | `443`                    |
| 🔌 Protocol       | `TCP`                    |
| ⚙️ Action         | `Allowed`                |
| 📌 Event          | `Connection established` |

### 💡 Example Log

```text
[10:32:15]

Source      : 192.168.1.20
Destination : 203.0.113.10
Port        : 443
Protocol    : TCP
Action      : Allowed
```

### 🛡️ SIEM

Logs can be collected and analyzed using a **SIEM (Security Information and Event Management)** system.

```text
🔥 Firewall ───┐
🚨 IDS/IPS ────┤
🖥️ Servers ────┼──→ 📊 SIEM ──→ 🚨 Alert
🌐 Network ────┘
```

# 🚨 E. Threat Indicators

**Threat indicators** are pieces of information that may indicate suspicious or potentially malicious activity.

### 🔎 Common Threat Indicators

| 🚨 Indicator                | 📖 Example                                |
| --------------------------- | ----------------------------------------- |
| 🌐 **Suspicious IP**        | Connection to a known malicious IP        |
| 🔗 **Suspicious Domain**    | Communication with an unusual domain      |
| 🚪 **Unusual Port**         | Unexpected service communication          |
| 📈 **Traffic Spike**        | Sudden increase in network traffic        |
| 🔄 **Repeated Connections** | Frequent connections to an unknown server |
| 📦 **Abnormal Packets**     | Unexpected packet behavior                |
| ⏱️ **Beaconing**            | Regular repeated connections to a server  |

> ⚠️ **Important:** A single indicator does not automatically mean that an attack is happening. Analysts normally investigate multiple indicators and the surrounding context.

# 🧠 Simple Understanding

Think of a network like a **road system**:

```text
🚗 Vehicles      → 📦 Packets
🛣️ Roads         → 🌐 Network
🚦 Traffic Flow  → 🌊 Network Traffic
📹 CCTV          → 👁️ Network Visibility
📋 Records       → 📝 Logs
🚨 Suspicious Car→ ⚠️ Threat Indicator
```

So, in simple words:

> 🛡️ **Network Traffic Analysis = Watching network communication, recording what happens, and looking for signs of suspicious activity.**
