# 🖥️ 4. Understand System Monitoring

System monitoring means **checking the health, performance, and resource usage of a Linux system**. It helps administrators and cybersecurity professionals detect problems, unusual activity, and resource exhaustion.

## 🔄 a. Process Monitoring

A **process** is a program or task that is currently running on the Linux system.**Process monitoring** in Linux is the practice of continuously observing running programs and system tasks to check their **health, resource usage, and stability**

### Common Commands

| Command | Purpose                                            |
| ------- | -------------------------------------------------- |
| `ps`    | Shows running processes                            |
| `top`   | Displays processes and resource usage in real time |
| `htop`  | Interactive process monitor                        |
| `pgrep` | Finds processes by name                            |
| `kill`  | Terminates a process                               |

### Example

```bash
ps aux
```

This displays detailed information about currently running processes.

---

## 🧠 b. Memory Usage

Memory monitoring checks how much **RAM** is being used, available, or cached by the system.

### Common Commands

| Command  | Purpose                                   |
| -------- | ----------------------------------------- |
| `free`   | Displays memory usage                     |
| `top`    | Shows memory usage by processes           |
| `htop`   | Interactive memory and process monitoring |
| `vmstat` | Displays memory and system statistics     |

### Example

```bash
free -h
```

`-h` means **human-readable**, so memory values are displayed in KB, MB, or GB.

---

## 💾 c. Disk Utilization

Disk utilization means checking how much **storage space is used and available**.

### Common Commands

| Command | Purpose                                 |
| ------- | --------------------------------------- |
| `df`    | Shows filesystem disk usage             |
| `du`    | Shows the size of files and directories |
| `lsblk` | Lists storage devices and partitions    |

### Example

```bash
df -h
```

This displays disk usage in a human-readable format.

---

## ⚙️ d. Service Management

**Services** are background programs that provide specific functions such as SSH, networking, or web services.

Linux commonly uses `systemctl` to manage services.

### Common Commands

```bash
systemctl status ssh
```

Checks the status of the SSH service.

```bash
systemctl start ssh
```

Starts the SSH service.

```bash
systemctl stop ssh
```

Stops the SSH service.

```bash
systemctl restart ssh
```

Restarts the SSH service.

### Common `systemctl` Operations

| Command             | Purpose                             |
| ------------------- | ----------------------------------- |
| `systemctl status`  | Check service status                |
| `systemctl start`   | Start a service                     |
| `systemctl stop`    | Stop a service                      |
| `systemctl restart` | Restart a service                   |
| `systemctl enable`  | Start service automatically at boot |
| `systemctl disable` | Prevent automatic startup           |

## 📊 e. Performance Observation

Performance observation means continuously checking whether the system is operating normally.

### Important Resources to Monitor

| Resource     | What to Monitor                      |
| ------------ | ------------------------------------ |
| 🧠 CPU       | CPU usage and system load            |
| 💾 Memory    | RAM usage and available memory       |
| 💽 Disk      | Storage usage and disk I/O           |
| 🔄 Processes | Running and resource-heavy processes |
| ⚙️ Services  | Failed or stopped services           |
| 🌐 Network   | Network activity and connections     |

### Useful Commands

```bash
uptime
```

Shows how long the system has been running and the system load.

```bash
top
```

Displays real-time process and resource information.

```bash
free -h
```

Displays RAM and swap usage.

```bash
df -h
```

Displays filesystem storage usage.

```bash
vmstat
```

Displays system performance statistics.

## 🔐 Cybersecurity Connection

System monitoring is important in cybersecurity because **unusual resource usage or unexpected system activity can indicate potential security issues**.

For example:

* 🚨 Unexpected processes may indicate suspicious activity.
* 🧠 Extremely high CPU usage may indicate resource abuse.
* 💾 Unexpected disk usage may indicate unwanted files or logs.
* ⚙️ Unknown services may require investigation.
* 🌐 Unusual network activity may indicate suspicious connections.

> **System monitoring helps security professionals understand what is happening inside a system and identify abnormal behavior.**
