# 📋 5. Understand Log Analysis

## 🔍 Overview

**Log analysis** is the process of reading and examining system-generated records to understand what is happening on a computer or network.

In cybersecurity, logs help detect **errors, suspicious activities, attacks, and unauthorized access**.

---

## 🖥️ a. System Logs

**System logs** record important events related to the operating system.

### Examples

* System startup and shutdown
* Hardware problems
* Kernel events
* System errors
* Application crashes

### Common Linux Location

```bash
/var/log/
```

### Useful Commands

```bash
cat /var/log/syslog
```

```bash
journalctl
```

---

## 🔐 b. Authentication Logs

**Authentication logs** record events related to users logging into or accessing a system.

They can show:

* Successful logins
* Failed login attempts
* SSH connections
* User authentication
* Privilege-related events

### Common Linux Location

```bash
/var/log/auth.log
```

### Example

```bash
sudo cat /var/log/auth.log
```

### 🛡️ Security Use

Repeated failed login attempts from the same source may indicate a **brute-force attack**.

---

## ⚙️ c. Service Logs

**Service logs** contain information generated by services or applications running on a system.

### Examples

* SSH
* Web servers
* Database servers
* DNS services
* Network services

### Using `journalctl`

```bash
journalctl -u ssh
```

This displays logs related to the **SSH service**.

For a web server, logs might be stored in:

```bash
/var/log/apache2/
```

---

## 🔎 d. Log Investigation

**Log investigation** means examining logs to understand an event or identify suspicious activity.

### Basic Investigation Process

```text
Collect Logs
     ↓
Filter Relevant Events
     ↓
Check Date & Time
     ↓
Identify Users / IPs
     ↓
Look for Suspicious Patterns
     ↓
Determine Possible Cause
     ↓
Take Appropriate Action
```

### Useful Commands

#### Search for Failed Login Attempts

```bash
grep "Failed" /var/log/auth.log
```

#### Monitor Logs in Real Time

```bash
tail -f /var/log/auth.log
```

#### View Recent Logs

```bash
journalctl --since "1 hour ago"
```

---

## 🚨 e. Security Indicators

**Security indicators** are signs in logs that may suggest suspicious or malicious activity.

| Indicator                        | Possible Meaning                    |
| -------------------------------- | ----------------------------------- |
| 🚫 Many failed logins            | Possible brute-force attempt        |
| 🌐 Unknown IP address            | Potential unauthorized access       |
| 👤 Unexpected user activity      | Possible compromised account        |
| 🔑 Login at unusual time         | Suspicious authentication           |
| ⚠️ Repeated service errors       | Possible attack or misconfiguration |
| 📈 Sudden increase in events     | Possible abnormal activity          |
| 🛠️ Unexpected privilege changes | Possible unauthorized activity      |

---

## 🧰 Useful Linux Log Commands

| Command      | Purpose                      |
| ------------ | ---------------------------- |
| `cat`        | Display a log file           |
| `less`       | Read logs page by page       |
| `tail`       | Show the latest log entries  |
| `tail -f`    | Monitor logs in real time    |
| `grep`       | Search for specific patterns |
| `journalctl` | View systemd journal logs    |
| `head`       | Show the beginning of a log  |
