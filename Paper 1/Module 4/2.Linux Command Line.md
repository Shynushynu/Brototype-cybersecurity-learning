# 🐧 2. Understand Linux Command Line

The **Linux Command Line** allows you to interact with the operating system by typing commands in a **terminal** instead of using a graphical interface (GUI). It is especially important in **cybersecurity** because many security tools and server environments are command-line based.

## 🧭 a. Navigation Commands

Navigation commands help you **move around the Linux file system**.

| Command  | Purpose                                 | Example        |
| -------- | --------------------------------------- | -------------- |
| `pwd`    | Shows current directory                 | `pwd`          |
| `ls`     | Lists files and directories             | `ls`           |
| `cd`     | Changes directory                       | `cd Documents` |
| `cd ..`  | Moves to parent directory               | `cd ..`        |
| `cd ~`   | Goes to home directory                  | `cd ~`         |
| `ls -la` | Shows all files, including hidden files | `ls -la`       |

### Example

```bash
pwd
ls
cd Documents
ls
cd ..
```

💡 **Simple idea:**
`cd` is like **walking into a different folder**.

## 📁 b. File Management

File-management commands are used to **create, copy, move, rename, and delete files and directories**.

| Command | Purpose                    | Example              |
| ------- | -------------------------- | -------------------- |
| `touch` | Creates an empty file      | `touch test.txt`     |
| `mkdir` | Creates a directory        | `mkdir projects`     |
| `cp`    | Copies files/directories   | `cp a.txt b.txt`     |
| `mv`    | Moves or renames files     | `mv old.txt new.txt` |
| `rm`    | Deletes a file             | `rm test.txt`        |
| `rmdir` | Removes an empty directory | `rmdir projects`     |
| `cat`   | Displays file contents     | `cat test.txt`       |

### Example

```bash
mkdir cybersecurity
cd cybersecurity
touch notes.txt
cp notes.txt backup.txt
mv backup.txt security_notes.txt
```

⚠️ **Warning:** Be careful with `rm` because deleted files may not be easily recoverable.

## 📝 c. Text Processing

Text-processing commands help you **read, modify, filter, and analyze text files**.

| Command | Purpose                             | Example                |
| ------- | ----------------------------------- | ---------------------- |
| `cat`   | Displays file contents              | `cat file.txt`         |
| `less`  | Views large files page by page      | `less file.txt`        |
| `head`  | Shows first lines                   | `head file.txt`        |
| `tail`  | Shows last lines                    | `tail file.txt`        |
| `grep`  | Searches for text patterns          | `grep "error" log.txt` |
| `sort`  | Sorts lines                         | `sort names.txt`       |
| `wc`    | Counts lines, words, and characters | `wc file.txt`          |
| `cut`   | Extracts sections of text           | `cut -d: -f1 file.txt` |

### Example

```bash
cat users.txt
grep "admin" users.txt
head users.txt
tail users.txt
wc -l users.txt
```

💡 **Cybersecurity example:**
`grep` is commonly used to search **logs for suspicious words, IP addresses, usernames, or errors**.

## 🔎 d. Search Operations

Search commands help you **find files, directories, and specific information**.

### `find`

Used to search for files and directories.

```bash
find /home -name "notes.txt"
```

### `locate`

Quickly searches for files using a database.

```bash
locate notes.txt
```

### `which`

Shows the location of an executable command.

```bash
which python
```

### `grep`

Searches for text inside files.

```bash
grep "password" config.txt
```

### Useful Comparison

| Command  | Searches For                  |
| -------- | ----------------------------- |
| `find`   | Files and directories         |
| `locate` | Files and directories quickly |
| `which`  | Executable commands           |
| `grep`   | Text/content                  |

## ⚙️ e. Administrative Commands

Administrative commands are used to **manage the Linux system, users, permissions, processes, and services**.

| Command     | Purpose                                 | Example                     |
| ----------- | --------------------------------------- | --------------------------- |
| `sudo`      | Runs a command with elevated privileges | `sudo apt update`           |
| `su`        | Switches user                           | `su username`               |
| `whoami`    | Shows current user                      | `whoami`                    |
| `id`        | Shows user/group information            | `id`                        |
| `passwd`    | Changes a password                      | `passwd`                    |
| `systemctl` | Manages services                        | `sudo systemctl status ssh` |
| `ps`        | Shows running processes                 | `ps aux`                    |
| `kill`      | Sends a signal to a process             | `kill 1234`                 |
| `shutdown`  | Shuts down the system                   | `sudo shutdown now`         |

### Example

```bash
whoami
id
ps aux
sudo systemctl status ssh
```

⚠️ Commands using `sudo` can make important system changes. Use them carefully.
