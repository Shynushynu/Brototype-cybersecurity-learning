## a. 📄 Log Parsing

**Log parsing** means reading and analyzing log files to find useful or suspicious information.

### 🔹 Common Commands

```bash
cat /var/log/auth.log
grep "Failed" /var/log/auth.log
awk '{print $1, $2, $3}' /var/log/auth.log
```

### 🔹 Example

Find failed login attempts:

```bash
grep "Failed password" /var/log/auth.log
```

### 🔹 Bash Automation Example

```bash
#!/bin/bash

echo "Failed Login Attempts:"
grep "Failed password" /var/log/auth.log
```

This script automatically searches the authentication log for failed password attempts.

## b. 👤 User Auditing

**User auditing** means checking users, groups, privileges, and login activity to identify unusual or unauthorized accounts.

### 🔹 Useful Commands

```bash
who
w
id username
cat /etc/passwd
cat /etc/group
last
```

### 🔹 Example

```bash
#!/bin/bash

echo "Current Users:"
who

echo "User Accounts:"
cut -d: -f1 /etc/passwd
```

A script can regularly check for unexpected users or login activity.

## c. 📊 System Monitoring

**System monitoring** means automatically checking the system's processes, memory, disk usage, and services.

### 🔹 Useful Commands

```bash
ps aux
top
free -h
df -h
systemctl --type=service
```

### 🔹 Example

```bash
#!/bin/bash

echo "CPU/Processes:"
ps aux | head

echo "Memory:"
free -h

echo "Disk:"
df -h
```

This helps detect unusual resource usage or system problems.

## d. 📑 Automated Reporting

**Automated reporting** means collecting security information and automatically creating a report.

### 🔹 Example

```bash
#!/bin/bash

REPORT="security_report.txt"

echo "Security Report" > "$REPORT"
echo "================" >> "$REPORT"

echo "Current Users:" >> "$REPORT"
who >> "$REPORT"

echo "Disk Usage:" >> "$REPORT"
df -h >> "$REPORT"

echo "Memory Usage:" >> "$REPORT"
free -h >> "$REPORT"

echo "Report generated successfully."
```

This creates a file:

```text
security_report.txt
```

Instead of manually collecting information, the script does it automatically.

## e. 🛡️ Security Administration Tasks

Bash can automate common **system administration and security tasks**.

| Task               | Command                      |
| ------------------ | ---------------------------- |
| Create user        | `useradd username`           |
| Change password    | `passwd username`            |
| Add user to group  | `usermod -aG group username` |
| Change permissions | `chmod`                      |
| Change ownership   | `chown`                      |
| Check users        | `who`                        |
| Check processes    | `ps aux`                     |
| Check services     | `systemctl status service`   |
| Update packages    | `sudo apt update`            |

### 🔹 Example Script

```bash
#!/bin/bash

echo "Checking system security..."

echo "Users:"
who

echo "Disk Usage:"
df -h

echo "Memory Usage:"
free -h

echo "Failed Login Attempts:"
grep "Failed password" /var/log/auth.log

echo "Security check completed."
```
