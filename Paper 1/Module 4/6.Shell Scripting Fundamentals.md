# 🐚 6. Understand Shell Scripting Fundamentals

Shell scripting is the process of writing a **series of Linux commands in a file** so they can be executed automatically. It is commonly used for **automation, system administration, and cybersecurity tasks**.

## 📦 a. Variables

A **variable** stores information that can be reused in a script.

### Example

```bash
name="Shynu"
echo $name
```

**Output:**

```text
Shynu
```

### Common Examples

```bash
username="admin"
count=10
directory="/home/user"
```

> ⚠️ **Note:** Do not use spaces around `=` when assigning a variable.

---

## 🔀 b. Conditional Statements

Conditional statements allow a script to **make decisions** based on a condition.

### `if` Example

```bash
age=18

if [ $age -ge 18 ]; then
    echo "Adult"
else
    echo "Under 18"
fi
```

### Common Operators

| Operator | Meaning               |
| -------- | --------------------- |
| `-eq`    | Equal                 |
| `-ne`    | Not equal             |
| `-gt`    | Greater than          |
| `-lt`    | Less than             |
| `-ge`    | Greater than or equal |
| `-le`    | Less than or equal    |

> 💡 `fi` marks the **end of an `if` statement**.

---

## 🔁 c. Loops

Loops are used to **repeat commands multiple times**.

### `for` Loop

```bash
for user in Alice Bob Charlie
do
    echo "Hello $user"
done
```

### `while` Loop

```bash
count=1

while [ $count -le 5 ]
do
    echo $count
    count=$((count + 1))
done
```

### 🔐 Cybersecurity Uses

Loops can be useful for:

* Checking multiple files
* Processing multiple users
* Analyzing multiple log entries
* Performing repetitive security tasks

## 🛠️ d. Functions

A function is a **reusable block of commands**.

### Basic Function

```bash
greet() {
    echo "Hello, Shynu!"
}

greet
```

### Function with an Argument

```bash
greet() {
    echo "Hello $1"
}

greet Shynu
```

Here, `$1` represents the **first argument** passed to the function.

## ▶️ e. Script Execution

A shell script is usually saved with a `.sh` extension.

### 1. Create a Script

```bash
nano script.sh
```

### 2. Add a Shebang

```bash
#!/bin/bash

echo "Hello World"
```

The `#!/bin/bash` line tells Linux to use **Bash** to run the script.

### 3. Give Execution Permission

```bash
chmod +x script.sh
```

### 4. Run the Script

```bash
./script.sh
```

You can also run it directly with Bash:

```bash
bash script.sh
```

## 🛡️ Shell Scripting in Cybersecurity

Shell scripting is useful for:

* 🔍 Automating security checks
* 📋 Analyzing log files
* 👤 Checking users and permissions
* 🌐 Gathering network information
* 📁 Managing files
* ⚙️ System administration
* 🚨 Monitoring suspicious activity

### Example

```bash
#!/bin/bash

echo "Current User:"
whoami

echo "Current IP:"
ip addr
```

This script automatically displays the **current user and network information**.
