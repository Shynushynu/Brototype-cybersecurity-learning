## 🌐 A. Linux Ecosystem

The **Linux ecosystem** is the collection of components and tools that work together to create a Linux operating system.

### 🔹 Main Components

| Component                   | Purpose                                                 |
| --------------------------- | ------------------------------------------------------- |
| 🧠 **Kernel**               | Core of Linux; manages hardware and system resources    |
| 🐚 **Shell**                | Allows users to interact with the system using commands |
| 📦 **Package Manager**      | Installs, updates, and removes software                 |
| 🖥️ **Desktop Environment** | Provides a graphical interface                          |
| 🛠️ **Utilities**           | Tools used for managing and operating the system        |
| 📂 **File System**          | Organizes files and directories                         |

### 🐧 Popular Linux Distributions

A **distribution (distro)** is a complete Linux operating system built around the Linux kernel.

Examples:

* Ubuntu
* Debian
* Fedora
* Arch Linux
* Kali Linux
* Red Hat Enterprise Linux (RHEL)

> 💡 **Cybersecurity Note:** Kali Linux is widely used for penetration testing, digital forensics, and security research.

## 📁 B. File System Hierarchy

Linux organizes files and directories in a **tree-like structure**.

The top-level directory is:

```bash
/
```

This is called the **root directory**.

### 📂 Important Directories

| Directory | Purpose                                            |
| --------- | -------------------------------------------------- |
| `/`       | Root of the entire filesystem                      |
| `/home`   | Personal directories of normal users               |
| `/root`   | Home directory of the root user                    |
| `/etc`    | System configuration files                         |
| `/var`    | Frequently changing data such as logs              |
| `/tmp`    | Temporary files                                    |
| `/usr`    | User applications and system utilities             |
| `/bin`    | Essential command-line programs                    |
| `/sbin`   | Essential system administration commands           |
| `/dev`    | Device files                                       |
| `/proc`   | Information about running processes and the kernel |
| `/boot`   | Files required for system booting                  |
| `/opt`    | Optional or additional software                    |
| `/mnt`    | Temporary mount point                              |
| `/media`  | Mount points for removable media                   |

### 🔍 Example

```text
/
├── home
│   ├── user1
│   └── user2
├── etc
├── var
├── tmp
├── usr
└── dev
```

> 💡 Think of `/` as the **main building**, and the directories inside it as different **rooms** with specific purposes.

## 👥 C. Users and Groups

Linux is a **multi-user operating system**. Multiple users can have accounts on the same system.

### 👤 Users

A user account identifies someone or something interacting with the system.

Two important types are:

* **Normal User** → Regular account with limited privileges.
* **Root User** → Administrator account with extensive privileges.

### 🔍 Check the Current User

```bash
whoami
```

### 👥 Groups

A **group** is a collection of users.

Groups make it easier to manage permissions.

For example:

```text
Developers
├── Alice
├── Bob
└── Charlie
```

Instead of giving permissions to each person individually, permissions can be assigned to the **Developers group**.

### 🔧 Useful Commands

```bash
whoami
```

Shows the current user.

```bash
id
```

Shows the user's UID, GID, and groups.

```bash
groups
```

Shows the groups a user belongs to.

```bash
sudo
```

Allows an authorized user to run a command with elevated privileges.

## ⚙️ D. Processes

A **process** is a program that is currently running.

For example, when you open a terminal:

```text
Terminal Program
      ↓
   Process
      ↓
   Running
```

Every process has a unique **PID (Process ID)**.

### 🔍 View Processes

```bash
ps
```

Shows processes associated with the current terminal.

```bash
ps aux
```

Shows detailed information about running processes.

```bash
top
```

Displays running processes and resource usage in real time.

### 🛑 Managing Processes

You can terminate a process using its PID:

```bash
kill PID
```

Example:

```bash
kill 1234
```

Here, `1234` is the process ID.

> ⚠️ Be careful when terminating processes, especially system processes.

## 🔧 E. System Services

A **system service** is a background program that performs a specific task.

Examples:

* SSH service
* Web server
* DNS service
* Network service
* Database service

On many modern Linux distributions, services are managed using **systemd** and `systemctl`.

### 🔍 Check a Service

```bash
systemctl status ssh
```

Shows the current status of the SSH service.

### ▶️ Start a Service

```bash
sudo systemctl start ssh
```

### ⏹️ Stop a Service

```bash
sudo systemctl stop ssh
```

### 🔄 Restart a Service

```bash
sudo systemctl restart ssh
```

### 🚀 Enable a Service at Boot

```bash
sudo systemctl enable ssh
```

### ❌ Disable a Service at Boot

```bash
sudo systemctl disable ssh
```
