## 🐧 A. Linux Ecosystem

The **Linux ecosystem** includes the Linux kernel, distributions, command-line tools, desktop environments, applications, package managers, and other software.

### 🔹 Linux Kernel

The **kernel** is the core part of Linux. It acts like a middleman between the hardware and the software. It manages:

* CPU
* Memory
* Hardware devices
* Processes
* Network communication
* System resources

### 🔹 Linux Distributions

A **Linux distribution (distro)** combines the Linux kernel with software and tools.

| Distribution                | Common Use                            |
| --------------------------- | ------------------------------------- |
| 🟠 Ubuntu                   | General use, servers, learning        |
| 🔴 Red Hat Enterprise Linux | Enterprise environments               |
| 🟢 Linux Mint               | Desktop use                           |
| 🟣 Kali Linux               | Cybersecurity and penetration testing |
| 🔵 Fedora                   | Development and modern Linux features |

# 📂 B. File System Hierarchy

## 📖 What is a Linux File System?

Linux organizes files and directories in a **hierarchical tree structure**.

Unlike Windows, Linux does not normally use drive letters such as `C:` or `D:`.

Everything starts from:

```text
/
```

This is called the **root directory**.

---

## 🌳 Important Linux Directories

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── tmp
├── usr
└── var
```

### `/home`

Contains normal users' personal directories.

```text
/home/farhan
```

---

### `/root`

Home directory of the **root user**.

> `/root` is different from `/`, which is the filesystem's root directory.

---

### `/etc`

Contains system and application configuration files.

Examples:

```text
/etc/passwd
/etc/hosts
/etc/ssh/
```

---

### `/var`

Contains frequently changing data.

Examples:

- Logs
- Caches
- Application data

Security analysts commonly investigate:

```text
/var/log/
```

---

### `/tmp`

Used for temporary files.

Because temporary directories can be abused by attackers, they are important during security investigations.

---

### `/usr`

Contains many user-space programs, libraries, and other shared resources.

---

### `/bin`

Contains essential user commands on systems where this directory is used separately.

Examples:

```text
ls
cp
mv
cat
```

---

### `/sbin`

Contains many system administration commands.

---

### `/dev`

Contains special files representing devices.

Examples:

```text
/dev/sda
/dev/null
```

---

### `/proc`

A virtual filesystem that exposes information about running processes and the kernel.

Example:

```text
/proc/1/
```

---

## 🛡️ Why the File System Matters in Cybersecurity

Security professionals need to understand where Linux stores:

- Configuration
- User information

- SSH settings
- Temporary files

For example:

```text

```

can contain evidence useful during an incident investigation.

## 👥 C. Users and Groups

Linux uses **users and groups** to control access to files, directories, and system resources.

### 👤 Users

A **user account** represents an individual or system account.

Common types include:

* **Normal user** → Used for everyday activities
* **Root user** → Has administrative privileges
* **System users** → Used by services and applications

### 👥 Groups

A **group** is a collection of users.

Groups make it easier to manage permissions.

For example:

```text
Developers
├── Alice
├── Bob
└── Charlie
```

Instead of giving permissions individually, permissions can be assigned to the **Developers** group.

### 🔐 Linux Permissions

Linux commonly uses three permission types:

| Permission | Meaning |
| ---------- | ------- |
| `r`        | Read    |
| `w`        | Write   |
| `x`        | Execute |

Example:

```text
-rwxr-xr--
```

These permissions determine what the **owner**, **group**, and **others** can do with a file.
