# 🔐 Understand Security Principles

Security principles are **basic rules and practices used to protect systems, networks, applications, and data** from unauthorized access, attacks, and failures.

## 🛡️ a. Defense in Depth

**Defense in depth** means using **multiple security controls** instead of depending on a single protection mechanism.

### Examples:

* 🔑 Strong passwords
* 🔐 Multi-factor authentication (MFA)
* 🧱 Firewalls
* 🛡️ Antivirus/endpoint protection
* 📊 Security monitoring
* 💾 Regular backups

> 👉 If one security control fails, other controls can still provide protection.

---

## 🔑 b. Least Privilege

**Least privilege** means giving users, applications, and devices **only the permissions they need** to perform their tasks.

### Example:

A normal user may be allowed to access their work files but should not have administrator permissions unless required.

> 👉 This limits the potential damage if an account or application is compromised.

---

## 🚫 c. Zero Trust Concepts

**Zero Trust** is a security approach based on the principle:

> **"Never trust automatically; always verify."**

### Key Concepts:

* 🔍 Verify users and devices
* 🔐 Use strong authentication
* 🎯 Provide only necessary access
* 📊 Continuously monitor activity
* 🔒 Treat every access request as potentially risky

### Example:

Being connected to a company's network does not automatically give a user access to sensitive information.

---

## 🧱 d. Security Layers

Security layers are **different levels of protection working together** to secure a system.

| Layer           | Examples                       |
| --------------- | ------------------------------ |
| 👤 User         | Passwords, MFA                 |
| 💻 Device       | Antivirus, encryption          |
| 🌐 Network      | Firewall, network segmentation |
| 🖥️ Application | Authentication, secure coding  |
| 📁 Data         | Encryption, backups            |
| 📊 Monitoring   | Logs, alerts                   |

> 👉 Multiple layers make it more difficult for a security incident to affect the entire system.

---

## ⚠️ e. Risk Reduction Strategies

**Risk reduction** means taking actions to **reduce the likelihood or impact of security incidents**.

### Common Strategies:

* 🔄 Keep software and systems updated
* 🔐 Use strong authentication
* 👤 Apply least privilege
* 💾 Maintain regular backups
* 🧱 Use firewalls and security controls
* 📊 Monitor system activity
* 🎓 Provide security awareness training
* 🧪 Regularly test security controls
* 🚨 Prepare an incident response plan

---

## 🎯 Key Takeaway

| Principle            | Simple Meaning                         |
| -------------------- | -------------------------------------- |
| 🛡️ Defense in Depth | Use multiple layers of protection      |
| 🔑 Least Privilege   | Give only necessary permissions        |
| 🚫 Zero Trust        | Verify before allowing access          |
| 🧱 Security Layers   | Protect different parts of the system  |
| ⚠️ Risk Reduction    | Reduce security risks and their impact |
