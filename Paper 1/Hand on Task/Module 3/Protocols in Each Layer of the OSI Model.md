# 🌐 Protocols in Each Layer of the OSI Model

## 📚 Layer 7 – Application Layer
- HTTP
- HTTPS
- DNS
- DHCP
- FTP
- SFTP
- SMTP
- POP3
- IMAP
- SSH
- SNMP
- NTP

## 🎨 Layer 6 – Presentation Layer
- TLS/SSL
- MIME

## 🤝 Layer 5 – Session Layer
- NetBIOS
- RPC
- SIP

## 🚚 Layer 4 – Transport Layer
- TCP
- UDP
- SCTP
- DCCP

## 🌍 Layer 3 – Network Layer
- IPv4
- IPv6
- ICMP
- IPsec
- OSPF
- BGP
- IGMP

## 🔗 Layer 2 – Data Link Layer
- Ethernet (IEEE 802.3)
- PPP
- IEEE 802.1Q
- STP
- ARP

## ⚡ Layer 1 – Physical Layer
- 100BASE-TX
- 1000BASE-T
- RS-232
- DSL
- SONET

---

**📝 Note:** The OSI model is a conceptual framework. Some protocols may be associated with different layers depending on the reference used. For example, ARP is often placed between the Data Link and Network layers, while TLS is commonly associated with the Presentation Layer in OSI teaching.
